## Motion direction

视觉结构少，时间层次有变化。动画按信息任务选择，不按“看起来酷”添加：

- F01：全候选身份 → 当前分组轴 → 候选逐层对齐 → 边界收束。当前资产只有一个
  实际轴，不能为了“Regrouping”另造两轴、重新排序语义或灰掉候选。
- G01：依据定位 → 路径节点每 0.45 秒展开 → 终点聚焦 → 闭合边界 → 阅读 Hold。
- R02：原文关系列连接 → 2 秒后候选关系进入 → 局部连接微移 → 4 秒后局部判定
  出现 → Hold。无红叉、镜头 shake；单项 verdict 不升级成整题答案。

Exit 采用语义段落/分页边界硬切；保留阅读到段末的机会，不用全屏转场盖住最后的
证据或字幕。位置预算 24px，局部修正 4px，overshoot=0，背景静止。高级感与是否
符合品牌的最终判断留给人工，不由这些数值自证。

## 中文入口与冻结事实

Hook 的短主句是既有 primary_text 的连续前缀，后半段以 Body 展示；两部分连接
逐字等于原冻结文字。既有痛点写法没有被模型改写。中文“方法边界”和关系列名是
固定展示词；局部排除标签只在既有 effect=eliminate、whole_question_answer=false
时显示。英文原句是 Evidence，仍完整保留；英文角色与 ID 只作 Metadata。

断行以实际字体测量、保守 16px composer 余量、中文标点及有限短语表为准。规则
不声称理解所有中文意群，不能可靠排下时分页/BLOCK；禁止让模型改写原句。
手机 QA 使用真实渲染缩放图，不能替代真实学生在手持设备上的测试。

## Platform projection

`platform-profiles.json` 与 Brand Grid 解耦。实际内容区由两者求交，字幕独立安全区。
CN_VERTICAL_GENERIC 和四个平台名目前共用保守的模拟排除区，明确标记 provisional；
这些值不是 App 实时 UI 或平台规则。日后可修改配置并提升版本，不分叉 Master。
覆盖区不改变 Evidence、Role、Stop 或 Claim。工程 footer 允许处于 UI 风险边缘；
关键教学文本不能。内部 Preview 必须保留 trace，本轮没有公开模板切换。

Render Contract v0.2 的增量只含 presentation profile、实际内容区和 cover_candidate
预留；原 teaching fields 不改。封面候选提供既有 Hook、中文方法名、focal scene，
通过 9:16/3:4/1:1 中心裁切图检查；不是正式封面系统或发布资格。

运行现有 CLI，在请求中显式添加：

```json
{
  "design": "../../../ae/design/swiss-academic-motion-v0.2.json",
  "platform_profile": "CN_VERTICAL_GENERIC",
  "revision": 1
```

其它 package/manifest/status/contract/output_dir 字段沿用 AE README；路径以请求
位置为准。每次视觉修订用新目录和 revision。v0.2 render identity 额外绑定实际
presentation projection 与平台 profile，映射代码变更也不能沿用旧 render ID。
v0.1 不改变身份算法，可以继续精确重放。真实数据和 A/B 图只留在忽略目录。
