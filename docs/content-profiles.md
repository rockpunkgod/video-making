# 两种产品，两套质量审核

本页执行 Experience First / Rigour First；当前真实试制采用 `FREE_SHOWCASE`。产品标记位于编辑交接层，不写入 ANSWER Registry 或稳定的 `voice-delivery/v1`。冻结教学事实、原题与声音消费接口保持原状。

## 共用硬门槛

Truth、最终实际展示的 Source Rights、No Fabricated Claims、No Unsupported Final Answer。逐题核验动作、Evidence、Role、当前判断和必要限定，再审核最终文案、展示与真实媒体。任何门槛未通过时不能公开放行。好看的片子不会因此得到教学认证，研究数据未完成也不会自动否决普通免费作品。

## 独立质量记录

| 产品 | 第一目标 | 内容组织主导 | 质量 Rubric 顺序 |
|---|---|---|---|
| FREE_SHOWCASE | 观看体验、认知爽感、传播力 | Creative Director | Hook / Engagement / Narrative / Cognitive Payoff / Visual Impact / Voice Performance / Memorability / Shareability |
| PAID_MASTERY | 严谨教学、独立掌握、迁移 | Pedagogy / Teaching Review | Teaching Accuracy / Evidence / Applicability / Boundary / Action Executability / Method Integration / Practice / Transfer |

每项记录具体判断、依据和待改位置；尚未看片、试听或进行真实教学核验的项目保持 PENDING。传播指标在实际发布前为 UNKNOWN。不给预想的留存、收藏、分享打“已验证”的分，不将两个 Rubric 求一个混合总分。

免费版中，一种核心方法组织一期，真实题目驱动各段。先给观看理由，真实操作产生突破，每题有自己的结果；第二题带来新的困难和观察路径。必要限定在它影响判断的地方表达，不要求把完整 Stop、反例、迁移数据念给观众。方法名称出现在简短辨识或回收中，不能代替题目叙事。

付费版设计从示范到独立练习的递进，实际覆盖适用条件、重要边界、组合、变式、错误诊断和反馈。First-use / Transfer 及宣传主张的核验需求按课程的实际目标记录。免费作品的传播成绩或审美认可不能充作掌握证明。

## 现有链路中的交接

| 环节 | FREE_SHOWCASE 本轮交接要求 | PAID_MASTERY 对应要求 |
|---|---|---|
| 选题 | 题目证据充分后，比较观看理由、真实反差、题间递进；不用热度猜测补分 | 比较教学目标、适用覆盖、练习与迁移设计 |
| Copy | 逐题正常引导、现场动作语言；后台保存完整来源与必要限定 | 自然口语下完整完成必要教学目标，不朗读机器字段 |
| Director | 先完整故事板、VO、节奏曲线和 Payoff，再决定技术缺口 | 学习活动和核验任务驱动镜头与节奏 |
| Motion | 同一 Signature 记忆，不同题独立路径；冲击由实际认知变化触发 | 让动作、对比、练习反馈可观察、可重复 |
| Voice | 呈现搜索、辨认、执行、判断与释放；新声音仍独立试听 | 清晰、自然、留必要思考和练习时间 |
| Premiere | 依实际声音重算字幕与时间；快慢、留白、音乐服务发现 | 不剪掉完成任务所需的观察、思考与反馈 |
| Human Review | 是否想看完、是否有真实爽点、是否想继续看；听感单独记录 | 能否独立执行、何时停止、能否迁移及常见误用 |

所有环节交接记录明确同一 `content_profile`；改变产品属于新的组织和审核版本，不继承另一个产品的质量结论。当前新发布检查器仅负责 Free Showcase，尚未实现 Paid Mastery 课程验收；不能给付费输入贴上免费标签绕过课程核验。

当前优先完成免费双题创作稿，技术变更按已定导演稿的真实缺口实施，不建设新的课程平台、收费系统或大型编排框架。

最新时长修正：用户不设时长要求或上限。所有既有 90–180 秒、150 秒、188 秒及导演区间只能用于描述草稿估计，不能作为选题、剪辑、生成或验收约束。片长由实际阅读、动作、思考、口播和必要停留决定；去掉没有新信息的重复，而不是压缩理解时间。
