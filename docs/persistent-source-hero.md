# 原句拆解：瑞士风内部试片

延续米白底、深色文字、低饱和绿、左对齐网格与大留白。用户明确要求题目一直放在
上方，并直接在题目上展示拆解过程。本修订仅制作一个已有冻结 Hero 的视觉版本，
不重做声音、不扩展音乐系统、不进入完整教学片生产。

## 画面规则

- 已绑定题干从首帧至末帧固定在上方，不随下方判断消失或移位。这里展示的是已有
  冻结摘录，不声称包含原题全部上下文，也不读取原始题库补充内容。
- 在空位与关键词下方依次画细线，随后用括号将已绑定的短语关系接到功能标签。
  线条从源位置生长，文字保持静止；不用跳字、弹簧、模糊转场或装饰性镜头运动。
- 当前判断和停止说明出现在下方。后段保留功能标签与原句，呈现未完成的判断及
  后续检查项目。保留全部受保护文案、否定词和 Stop Rule。
- 中文采用 Noto Sans SC，英文原句沿用 Georgia；主要源文字 68–72px，补充文字
  最小 46px（1920×1080 画布）。字幕沿用经核验的 PR 样式，不据此宣称手机阅读通过。
- 使用原有 14.75 秒声音和两段真实 Hold。较长限制说明的阅读负担仍需观众反馈，
  不将这一短片当作完整解题教学，也不宣称学习效果已认证。

## 重放

`python -m creative_os.hero_action <local-request.json>` 接受 `base_contract`、
`package`、`manifest`、`statuses`、`full_delivery`、`excerpt`、`revision`、`output`。
`output` 是尚不存在的契约 JSON 文件；所有真实输入与输出保存在忽略目录。

输入必须含当前消费者 Hero 的完整文字角色。生成器保持文字、unit 归属、copy lock
及教学范围不变，重新安排版式和批注。批注的 `annotation_refs` 只记录视觉指向，
不是新增教学声明或语义认证。其他题型不能直接套用这组短语关系；需先设计并审阅
与其冻结动作相符的布局。

按 [Hero 工作流](cinematic-hero-workflow.md) 保存新的 AEP 修订、原生构建、审计，
再通过 TIFF 中间帧生成无声视觉段。PR 另存新修订，替换视觉段，保留绑定声音与
字幕，重新导出并绑定实际显示帧。旧工程、凭证和试片不覆盖。

审阅对象是实际导出：首帧、画线中点、关系建立、停止、限制说明；同时检查原生
无损 Hold、字幕、声音、上游依赖与最终文件 hash。教学、来源、音乐、编辑及人工
口味审核独立保留；本内部试片 `public_render_ready=false`。

设计借鉴来源及边界见 [文献与 GitHub 复审](visual-reference-research-2026-10-06.md)。
本实现自行编写，不引入第三方动画代码、视频或图片。公开仓库仅保存工作流、代码、
脱敏报告和合成测试；真实题干、视频、音频与 Adobe 工程不提交。

- 实际导出首帧、画线中点、关系建立、判断及边界静帧已检查：无文字重叠或截断。
- 新 AEP/PR 工程、显示绑定与凭证保存在本地，公开资格保持 false。技术通过不代表
