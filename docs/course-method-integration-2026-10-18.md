# 已核方法的制作入口对齐

对照 ANSWER `1c388a0596b13935ae7c6a1af00834915a8efa33` 与 video-making `3f30b668496ce8fe6d08906daab0305cecd0d889`。本次补参考定义、制作映射及草稿导演消费；不迁移 ANSWER 求解 Registry 的来源纪元，不重写 Frozen Asset Bundle、历史案例或审阅凭证。课程原始核验复用上游本次遗漏复核；不是新增学生效果验证。

## 发现与取舍

| 缺失／未正确接入的职责 | 制作收益与场面 | 使用条件与停止点 |
|---|---|---|
| 连连看、一一对应 | 保留候选共同部分，叠合正文与选项的完整关系，让主体、动作、修饰或范围的差异留下；优先考虑竞争项局部慢放 | 已定位正文且差异确实影响当前判断；同词、对应数量或表面句式不定案。两名称分别保留，不把 R03 改名或自动注册两套算法。 |
| 最短逻辑、逻辑最近 | 已证关系连续呈现；候选额外需要的前提作为未证缺口显影，形成“为什么这个选项看着对却接不上”的回报 | 新增前提及正向支持须由冻结动作给出，动画不自行发现前提。不得按词距、句位、字数或推理步数选答案。 |
| 大词原则、大小原则 | 比较完整断言覆盖的范围，展示候选多包进了什么、正文实际只支持哪一层 | 先确认完整语义包含；主题相关不算包含。宽泛健康判断与具体益处不能只因同主题就套此法。较宽候选新增对象、动作、范围和条件都需支持。 |
| 词义题两项原职责 | 对标表达与连接关系相继进入视野，最后比较同向候选的具体词义 | 词性只定位、逻辑词须核两侧内容，附近不足扩看正文；不另造“新方法名”。 |
| 七选五代词指代法／代词指代 | 把代词还原为冻结动作已确认的实体、事件或概括内容，显出候选与空后承接的差异 | 是已有对应词／主体核查子动作，不新增第八法、不重做开头三一致；形式 it 不强找名词，不运行一定含名词项。 |
| 完形复现分支、结构对应、动作流 | 对照真实对象、动作和语境关系；同义竞争仍落具体语义 | 复现名称不是定案条件；and 可接反向处境，不推反义方向；不设固定空号、遍数、配平或三贬一褒。 |
| 图片定位法、构图定位法 | 直接相关物象帮助记住候选区别，再随焦点回原文；作为定位辅助 | 无有效物象就停。画面不补心理、事件或因果，不将图片记忆法各版本全部合并；定位命中不是答案回报。 |
| 应用文句子写作思路、开放层面构思、感谢信呼应 | 分别承担句子组织、开放要点选择和感谢信结构提示 | 个人—家庭—学校—社会不是四段模板；感谢信结构不套全部书信；不增评分项或强制复杂句。 |
| 续写同名三化、gap、旧PPT版本及仿写材料 | 提取故事线索、显示过程空缺或组织已给提纲 | 不借阅读三化定义；gap 不拆字母；十句不强制、版本不混用；动作面定义未全，素材不升算法。 |

新目录只登记对当前制作有实际价值的职责。诊断词、训练数量、材料标题、费曼学习法等没有因此获得判题权限。结构词做题法仍只有单例入口，不凭 and／also 激活独立算法。

## 制作合同与实际消费

`creative/method-choreography/course-method-mapping.json` 分别记录名称、题型、上游精确章节、定义摘录、触发、Stop、相关旧编号及电影化意图。相关编号仅表示职责交集；不参与运行匹配。目录不赋予判题、传播或原生渲染权限。

`content_os.director.build_draft()` 在既有 bundle、claim、action、review 与状态门禁通过后，对实际 COMPARE 动作调用 `content_os.course_mapping.action_visual_intent()`。该消费只读取名称、题型、来源定位、动作状态和展示字段；不从参考定义生成旁白、推理、选排或新事实。输出仅改变该场景的 `visual_intent`，原 claim、output、证据、Stop 及 method_name 均按冻结内容保留。

启用需同时满足：冻结 `source_name` 与目录名称相同；题型相同；来源 repository、完整 commit、path、heading 相同；动作 method_id、版本和角色相符；动作 produced、reviewed、未触发 Stop 且有证据及 Stop 检查；输出属于对应辅助角色。别名、相似名称、相关旧编号、旧提交、缺证或定案型输出均不启用。未匹配时保留 `show_bound_information`。

目录的 `competition_focus` 是选材与分镜优先级，不是“这个方法出现就说明学生会错”的统计结论。编导仍需从本题审阅记录确认真实竞争项。先显示原任务和仍竞争的候选，再只慢放冻结动作确认的关键差异，回报只报该动作已产生的缩小、核验或定位结果。明显不一致项可短展示其既有排除结论；完整题目的闭合记录与必要证据仍保留，不从未讲的项推答案。不为展示目录而堆方法。

这些视觉意图尚未扩展已有六套 Motion Identity 或原生 AE 3D 编译器。当前接通的是语义场景入口；导演可据此实施镜头与物理动作，不能把映射测试通过写成完整成片或原生动画已实现。
