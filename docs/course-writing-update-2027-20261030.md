## 学生现在先做什么

写不出来时先圈题面三样：写给谁、要办什么事、必须写到哪些信息。把每个必写信息放进一条准确简单句，再决定是否合并或加修饰。不要先选高级词、被动句或倒装句。

拿到一封信，先让主体段承担当前任务：

| 当前任务 | 主体段手上要做的事 | 停止套模板的信号 |
|---|---|---|
| 建议 | 针对题面困难给具体建议，并说明对应理由 | 建议与困难无关，或为了模板强凑三条 |
| 感谢 | 写清对方做了什么、怎样帮助自己 | 把主体写成给对方提建议，或编造题面不支持的帮助 |
| 求助 | 说清卡在哪里、希望对方具体帮什么 | 只写“帮帮我”，却没有所求内容 |
| 邀请 | 介绍当前活动及对方参与的角色，发出邀请 | 把参加者、评委和志愿者混成同一角色 |
| 申请 | 将真实相关能力、经历对应到所申请职位 | 为填模板虚构履历，或只罗列性格而不对应职责 |
| 告知/回复询问 | 把具体安排或对方所问信息逐项交代 | 套上无关邀请、请求回复，或漏掉实际变更 |

题面给定的人物、时间、地点、活动和写信身份优先；需要自行安排的细节须符合任务，不能冒充已给事实。学生会/体育部等机构署名只用于题面确实要求该身份的场景，不推广为所有告知信都禁止个人署名。

## 与现有方法的关系

- A01作文五检：秋3回放轴第2页重申文体目的、内容要点、细节、格式、词数；仍逐项回题面与现稿核对，不把模板列出的项目增为每题义务。
- A03三步造句：暑8讲义以谓语、结构、主谓宾、修饰和词语优化作句子训练提示。学生入口仍先说清谁做什么，再补必要细节；后续修饰和换词可选，不另造每句必须完成的五层升级。
- A04/A07：句法与语义成立才合句或扩写；可以保留准确简单句。不把“两简一复从”和不同来源的“反向劫匪插葱”合成一种操作。
- A08文体骨架：新增六类信件的本课具体职责对照，使用上表组织当前要点。基本/升级模板是可选素材，不要求每篇三段、三条理由或指定从句。
- A10训练阶段：暑8的先写对写完整、再优化表达可供训练分流。按学生现稿缺口选择，不因季节到了就强迫基础学生换高级词和复杂句。

暑8原件保留“大小三圈”称呼：用自我、同学、社会等角度扩展思路，并从是什么、为什么、怎么做细化一项内容。只在题目确需展开且该角度相关时用；不强制三圈写齐，不把每条建议拆成三句，也不借阅读“大词原则/大小原则”的定义。
