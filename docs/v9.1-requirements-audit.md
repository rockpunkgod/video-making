## 前序要求与最终文件核验

- 完整 Human Voice Script 与独立 Hero 摘录均保留；冻结否定限定、Role、Stop
  和逐句引用未改为完整解题结论。音纹按用户要求后置。
- 三方向各 Hook/Core/Stop，共九张实际原生 AE 静帧存在。
- 当前冻结 Package、Manifest、状态清单与全稿/摘录通过契约门禁；AEP、模板、
  AE 视觉输出与 Render Receipt 通过 handoff 校验。
- 最终导出文件 hash 与生产 Manifest 一致，Audio Plan hash 一致；
  Creative Review 对应同一导出，恰有 19 项维度。
- 原生 PR 回读声音片段覆盖与全部配乐关键帧。修正旧声音描述后重新导出，
  解码视频帧与音频样本分别与之前交付一致。声音计划验证不代替人工试听。
- 最终字幕、文案 Copy Lock 与实际展示片段 Source Display 已绑定；
  `editorial_review_sha` 仍为空，公开资格仍为 false。
- 一首用户提供的夜曲为内部 scratch，录音授权未证明；音乐五问仍待人工。
  没有扩展复杂 Music System。
- 当前实时 PR 是官方上游 MCP 的 CEP 连接；UXP 静态契约不冒充在线能力。

实际媒体、工程、题面、运行请求与认证信息全部留在忽略的 `local-data/`。
公开仓库只保存实现、规格、工作流、合成测试和本脱敏审计。
