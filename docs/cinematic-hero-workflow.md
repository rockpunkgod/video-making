# V9.1 G01 Hero workflow

Production remains on the V9.1 branch of work. The producer consumes explicit
frozen package, package manifest and current supplied status files. It never
reads a teaching Registry, teaching Markdown or a raw question bank.

1. Keep the full Delivery Copy. Author a distinct-ID bounded excerpt; retain
   its frozen Stop Rule, role, negative qualifications and claim references.
2. Run `python -m creative_os.hero <local-request.json>` to create a 10–15s,
   1920×1080, 24fps contract from explicit bound text/shape nodes. Request keys:
   `package`, `manifest`, `statuses` (asset ID → local path), `full_delivery`,
   `excerpt`, `design`, `nodes`, `beats`, `duration`, `revision`, `output`.
   Every text node projects its own unit's screen copy or literal evidence.
3. Bind `design.motion_identity` with `creative_os.motion_identity.bind_identity`.
   Each Shot Plan identifies the frozen semantic scene, method/signature/phase,
   brand motions and purpose of structural/depth/accent effects. The visual
   registry cannot supply facts or applicability conditions.
4. Use `ae_production.hero_execution.build` / `render` with the official
   JUNKDOGE client. Save to a new project revision before a checkpoint. Verify
   native text/font/canvas/effect policy and expressions, then render motion
   only. `creative_os.hero.render_receipt` binds AEP and output file hashes.
5. Use `premiere_production.editorial.EditorialSession` with the installed
   leancoderkavy server. `replace_motion` preserves source/timeline bounds and
   verifies them. VO, one scratch piano bed and sparse SFX are separate tracks.
   `premiere_production.music.apply_music` writes native localized audio Level
   keyframes and returns actual readback. No second Adobe script bridge.
6. Save final PR project, then `python -m premiere_production.editorial
   <local-premiere-request.json>` for an **internal** native export. Request
   keys: frozen paths from step 2, `contract`, `render_receipt`, `ae_project`,
   `audio_plan`, `captions`, `sequence_id`, `edit_receipts`, `endpoint` (local
   loopback MCP), `token_file`, `backend`, `output`, `export_preset`,
   `production_manifest`. Keep tokens, paths and requests in ignored data.
7. Decode the entire export, probe duration/frames/audio, inspect burned-caption
   frames, verify Hold frames and inspect native music key readback. Store
   final caption text/timings and displayed excerpt/image hashes in the local
   production manifest. All render/playback verification is separate from
   the upstream tool's parameter-storage receipt.
8. Produce copy/visual/audio-bound Creative Review. Human taste, brand recognition
   and listening remain pending until answered by a human. Use the five music
   questions; do not build a music scoring engine.

The export request Audio Plan binds `render_contract_sha`, `final_copy_sha` and
each voice file's SHA, unit ID, spoken-copy SHA and claim refs. It also binds
recording source and derived clip hashes. Changed copy, files or current frozen
dependencies are rejected before pipeline operations. Status snapshots do not
provide live monitoring of external withdrawals.

The router requires a verified live backend and actual advertised tools. A
static UXP capability entry does not establish a live UXP connection. It refuses
silent fallback and blocks further edits after an uncertain operation. Inspect
native state and reconcile deliberately before continuing; do not blindly retry.
The current installed producer is CEP; UXP mappings remain explicitly unverified.
The restricted Codex catalog now contains 30 typed tools, including the generic
keyframe writer/readback used with Chinese-localized Volume properties.

Caption styling is a native PR project style, not an assumed MCP capability.
Native export needs an explicit installed preset. Keep any local derivative EPR
outside Git. The current Adobe preset's tested caption option 2 burns captions;
option 1 exports a sidecar. Verify these on the active host rather than relying
on a number alone. The CEP host may coalesce overlapping SRT cues; preserve
the actual native caption text/timing readback in export evidence.

Music License, Teaching Release, Source Display Release and Editorial Release
are separate gates. This pilot exporter always sets public readiness to false.
A final text or subtitle change invalidates editorial approval. Source review
must bind actual displayed text/images, not only the abstract question source.

No full G01/F01/R02 production and no V10 until human `APPROVED_DIRECTION`
binds the current render contract. No commercial recording, generated video,
voice WAV, AEP, PRPROJ or real question asset belongs in the public repository.
