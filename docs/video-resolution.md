# 视频交付清晰度

用户于 2026-10-09 要求统一 4K 清晰度。后续新制的横版预览、内部粗成片和
满足独立发布门禁的正式交付，统一使用 **3840×2160、16:9**。
帧率沿用各条已绑定的制作规格；当前 Method Relay 定位实验为 24 fps。

AE 以 4K 合成、完整分辨率渲染原生帧。字形、文字布局、相机、对焦、高亮、
遮罩和留白一起按原构图比例进入新画布，保持教学内容、阅读顺序和镜头时长。
打包后核验实际编码尺寸、帧数、帧率和完整解码。

当前完整原文定位实验的请求包含 `canvas=[3840,2160,24,20]` 和
`render_scale=2`。布局坐标继续保留在原设计空间；AE 原生文字对象、相机与
焦点在 4K 场景中等比例绘制，画布和实际变换都接受原生读回检查。
FFmpeg 负责打包已经是 4K 的原生帧。

后续进入 Premiere 时，新序列与新画面按相同的 3840×2160 建立并核验导出；
本次定位镜头仍按已约定的人工视觉审核门禁停在独立无声预览，不提前集成全片。

4K 修改属于画面呈现变化，生成新工程、spec SHA、原生帧和媒体 SHA，并重新
绑定受影响的画面/编辑审核。它不改变教学语义绑定，不新增人工认可，也不解除
教学、来源或公开发布门禁。声音和配音文字保持各自已有绑定。

历史已认可和历史研究文件保留原始尺寸与 SHA；它们的审批及重放记录继续绑定
原文件。新的 4K 版本保存到新的本地修订目录，媒体和 Adobe 工程仍留在忽略的
本地数据目录，GitHub 只保存工作流、测试和脱敏报告。
