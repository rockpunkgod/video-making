# Reality Layer + Cognitive Space · 单镜头创意预演

2026-10-11。延续 FREE_SHOWCASE 的 Experience First：先用一条真实案例验证观看方式，再决定是否进入原生高保真制作。本轮沿用现有冻结消费和候选状态审计，不增加教学编译器、导演 Runtime 或新方法。

## 两个空间，一份来源

**Reality Layer** 是同一个原题世界：完整原文、题干和原选项保持稳定位置。镜头允许局部对象离开视野，但不换成另一张解释卡。建立全景后，位置、尺度和短暂颜色变化表达当前注意力；原文没有被改写成知识点列表。

**Cognitive Space** 是临时工作记忆：从实际被看到的原词位置提取透明文字投影，保留父对象、精确范围及来源绑定。发现先发生，投影后进入。它表达已经发现的关系，不生成新的教学事实。

比较时，来源中的归属对象先建立关系，选项里的相近表达随后靠近。不同归属保持空间分离，直到已冻结判断发生。候选状态由原 Action 决定；运动不能升级其结论范围。

判断结束后，临时投影退隐，原文重新清晰，镜头连续返回原选项。原位置和选项身份保留，变化体现在实际候选状态中。第一遍导出的文字回归出现叠加，独立 r02 改用退隐与重新聚焦，r01 保留。

## 这一条的导演顺序

| 时间 | 镜头与认知操作 |
|---|---|
| 0–3s | 完整原文和原题建立同一个世界 |
| 3–5.2s | 题干对象成为当前注意目标 |
| 5.2–7.6s | 镜头进入原文，确认相关角色语境；题干目标进入临时记忆 |
| 7.6–12.8s | 注意力接近来源句，短暂比对，再确认整句 |
| 12.8–16.5s | 来源文字保持原换行结构，整体进入透明工作空间 |
| 16.5–20s | 同一批原词重新分组，呈现已审阅的归属关系 |
| 20–26.3s | 原选项投影进入比较，相近表达靠近，归属差异留在画面中 |
| 26.3–28.5s | 已冻结的单候选判断发生，留出短暂收稳 |
| 28.5–33s | 工作空间退隐，原文重新清晰，镜头返回原题 |
| 33–40s | 原选项及其更新状态可见，再回到完整世界 |

题干与归属焦点使用橙色，比对使用蓝色，来源确认短暂回到橙色。没有划线、卡片框、概念标题、新口播或弹跳动效。镜头与文字运动采用平滑插值；是否自然仍由实际观看判断。

## 私有制作交接

私有 `PLAN.json` 保存来源、动作、原词范围、投影父对象、阶段时间和候选事件。`render.py` 是单案例作者实验；字体和被复用的作者程序分别保存 SHA。每个 revision 使用独立目录，不覆盖历史视频。

`FRAME_STATES.json` 记录镜头、父世界、投影身份和当前候选；`MEDIA_RECEIPT.json` 绑定实际视频、计划、程序、字体和帧状态。`ACTUAL_FRAME_MAP.json` 保存编码后抽查帧及 SHA。沿用 `ae_production.experience_proof` 与 `audit_candidate_events()` 核验冻结引用和判断顺序；字符定位与状态检查不等于语义认证或观看理解。

全片按 **1920×1080、24 fps、Rec.709、40 秒无声 EDITORIAL_PROXY** 输出。正式4K要求保留，本轮仅执行已授权的低成本创意预演，不操作 Adobe 宿主。媒体与真实题材保留本地，公开仓库只保存流程和脱敏报告。

## 当前认可与后续使用

核验结果见 [本轮验收记录](../REALITY_COGNITIVE_SPACE_PROOF_ACCEPTANCE.md)。2026-10-11，用户反馈“这个方向很对”，混合影像方向已获认可，可作为后续镜头的设计基线。

具体镜头继续分别检查：发现过程是否连续；比较是否从原文中长出来；返回原题是否自然；是否有现场参与感。此次方向认可不代替这些逐项记录。声音、教学效果、正式原生字形和公开发布各自保持原状态。
