# 给文案 Agent 的交接：自然口语与学生做题视角

这份说明提取现行规则，供另一位 Agent 改进写作规范与候选文案。它不批准新口播，也不改变冻结教学、教学选择或发布状态。

## 项目背景

仓库是 `rockpunkgod/video-making`。产品面向高考英语学生，展示一个方法在真实题目中的应用。学生先看到原题，再随着画面做出第一动作，看到当前结果，并知道做到哪里够了、哪里还不能下结论。一个视频默认承担一个主简化；完整方法的边界、反例与迁移可以拆成后续内容。

现有链路：ANSWER 冻结教学事实 → Pedagogy Compiler / PedagogyPlan → Student POV Copy → Motion / Shot → AE → Premiere。ANSWER 拥有事实、角色与生命周期；Compiler 决定哪些内容现在必须讲；Copy 只改变表达。画面保留克制、典雅的 Swiss 方向，运动、配乐和停顿都为方法动作服务。C端只显示有用的内容与方法名，不显示 R01/G01 等内部编号。

工程层已经有契约、绑定、审计和模拟适配器；还没有接入真实语言模型来自动写自然文案。当前默认实现主要逐字投影 Plan。结构规则与写作指导是两部分；字段通过不等于自然口语或学生体验已通过。

目前同步的是既有 G01 bounded worked_example 草稿。它只到已有名词性功能路线，具体词形仍未闭合；不能排除全部动名词，不能写成已经填出答案。Compiler/Copy 0.3 保留完整原题与持续题面层，未知风险的冻结 Caveat 仍进入十条 Tell Now；first_touch 因边界负荷 HOLD。G01 当前没有受支持的真实工作减少，不因口语改得自然而获得 Payoff。当前定稿已由独立 AI 文本复核，绑定最终文字与逐景脚本；这份凭证不代签真人听感或 Human Taste。

唯一新增的受支持Golden完整题型文案选择R02：既有审阅的局部排除支持当前候选4→3，未观察学生原路径或验证提速。用户明确不要结果后的安全提醒，本轮Pedagogy已逐项审阅九条Tell Now：1/2/3/8用关系对比与实际中性候选状态覆盖，4/5/6/7/9只因当前未触发而后置，frequency仍unknown。详见`R02_BOUNDARY_RISK_REVIEW.md`。Copy消费这个显式决定，不自行分级；新稿省去提醒墙，不把同样废话搬成字幕。G01同步稿删除Stop VO，但没有做该资产的风险降级或补Payoff。

## 已有的“人味”要求，优先改这些

原始用户补充的第九至十二、十四至十五、十九至二十二节，以及后续第二十三至二十七、三十三、三十九至四十一、五十至五十一节，是表达层的核心。其要点是：

1. 从当前题面中学生会卡住的地方进入，不从“今天我们学习……”或课程背景进入。不能虚构学生比例、学生想法或普遍痛点。
2. Student POV 指思考位置，学生应感觉自己在做题；不要求每句都写“我先、我再、我然后”。
3. 用能对应眼睛、笔尖或下一步操作的语言，例如看、圈、拆、比、留、停。抽象概念只在学生此刻确实需要时出现。
4. “先别……”用于有依据地阻断旧路径；“只看……”用于明确注意对象。它们是可选表达，不是每条片子必须重复的口头模板。
5. 一个第一动作来自 Plan。不要为了自然感补新的英语规则，也不要把整条专家推理链念出来证明严谨。
6. VO推进思考与下一动作；Screen放原文、Evidence与当前产物；Motion展示抽离、重组或范围变化。用户不要结果后的检查清单式提醒，也不移到字幕。必要Stop/Tell Now的教学功能必须按Pedagogy已审安排覆盖，不等于每句后台原文都要重复念出。
7. 有依据的结果出现以后，一句短反应或 0.3–1.0 秒停顿即可。不要追加十秒总结，也不要为凑30/60/90秒增加解释。
8. 定位、缩小范围和得出答案必须说出各自真实程度。不能把“暂时放后面核”说成“以后都不用做”。
9. 方法名放在动作价值之后；最后留下学生下一题能调用的第一动作。不要把“记住方法编号”当作记忆目标。
10. 成功标准是学生知道下一题第一动作、能识别当前产物与适用边界；不是强制学生复述安全提醒。画面酷、分析详细、程序lint PASS都不能替代这个判断。

最直接的原话是：“Student POV 是思考位置，不是第一人称代词密度。”“Copy 应该能对应笔尖动作。”“不要让 VO 重复解释画面已经完成的事情。”这些指导的是思考和表达，不是要求某些词一定出现。原始第十至十二节的“先别”“只看”是示例；改稿时可以提出更自然、同样有来源支持的写法。

## 当前表达问题与允许质疑的地方

初版规范对“不能错”和字段完整性写得较具体，对自然措辞、语气与句间衔接写得较少。另一位 Agent 已在 `docs/student-pov-copy.md` 新增“自然口语：写学生怎么想，不写字段怎么读”：从为什么现在说、能否听一次就懂、指代是否清楚入手，要求试念并检查画面锚点。后续审查把普通书面词和重复句式调整为表达倾向，避免它们再次变成禁词表或机械模板；工程 AI/人工 Copy 凭证也与真人听感、Human Taste 分开说明。

逐字搬运 Plan 会把内部表述带到口播；机械执行短句原则又容易变成一串“先别 → 只看 → 先停”。“动作语言出现”“没有套话”只是信号，不能证明一句话有人味。目前没有独立接入的完整自然写作模型提示词；改进对象首先是这份写作规范，然后是显式候选接口，不能只改 lint。

请围绕具体题面改进语气与表达：这句话为什么现在说，学生能否听一次就懂，省略对象后还能不能理解，是否真的适合开口念。允许长短句变化、必要衔接、轻微反应与自然停顿；不用强制每句短指令，也不用硬塞反问、感叹、网络梗或“咱们”。不要预设学生已经认识所有术语，也不要用成串后台术语制造严谨感。

可以质疑表达规则与候选措辞，提出替代写法和理由；不能自行决定 Tell Now / Tell Later，不能降低 Role / Evidence / Stop 约束，不能补未认证的认知收益。

## 给另一位 Agent 的具体任务

请先读现行说明与候选材料，完成两部分：一份改进后的自然口语写作规范，以及一个真实候选的逐句改写提案。指出原规则哪里容易诱发机器味，保留必要规则，增加可操作的语感指导。每句提案记录原文、改写、改写理由、保留的 Plan 引用、对应 Screen / Motion、边界是否完整；不要直接覆盖历史最终 Copy。

只处理表达层。审阅支持缺失的 Payoff 继续标 UNKNOWN / HOLD；给出待审写法也不能宣称已经省掉某项工作。最终自然口语、语义保真和 Human Taste 等待独立审核，修改后的文案不能沿用原编辑批准。

## 修改位置

公开仓库内：

- `docs/student-pov-copy.md`：首先读“自然口语：写学生怎么想，不写字段怎么读”，再读“学生体验与文案契约”“VO / Screen / Motion 与 Signature”“Silence 与 Explanation Suppression”。这里是现行说明。
- `student_pov/realization.py` 的 `realize`：消费轻量投影；`adapter.propose` 或显式 `draft_lines` 输入候选表达。可改字段是 pain / interrupt / focus / first_action / cognitive_relief_line / payoff_line / stop_vo / memory_phrase。这里是接口与默认投影，不是完整写作提示词。
- `student_pov/qa.py` 的 `lint_copy` / `suppression_qa`：确定性禁说与去重复候选，不能判定人味或完整语义真值。
- `creative/copy-system/student-pov-copy.schema.json`：句子、来源与场景结构。不要为改善语感取消来源、Stop 或审核绑定。
- `STUDENT_POV_HUMAN_TASTE_REVIEW.md`：真实学生/人工应回答的体验问题。
