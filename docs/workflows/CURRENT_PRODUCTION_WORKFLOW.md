## 文章词块：先读句意，再排版与运动

负责者是制作作者中的**文章词块编辑**。先读完整冻结文章，再在私有 `ARTICLE_CHUNKS.json` 标明连续意群；`ae_production/article_chunking.py` 编译成 `READING_CHUNKS.json`，并导出可独立查看的 `ARTICLE_CHUNKS_REVIEW.html`。这是语言编辑职责和校验器，没有声称部署了一个自动理解英语的模型。

- 保留固定搭配、完整名词短语、专有名称；按从句、并列和自然语义停顿切分，不凑相同词数。
- `take part in`、`high school writers`、`GrubStreet’s previous summer programs` 等不能被切成两次放大。易误拆处写入源文精确匹配的 `keep_together`。
- 划分覆盖整篇文章，保留全部字符、原词和标点；空白由原文保留。相同段落的 scope / scan / hit / 复看共用一套词块身份。
- 原文或划分改变后必须重新编译；`prepare / build` 不接受缺失或过时划分，已有原生工程必须另存新修订。
- `prepare → AV_PLAN.worlds.blocks.reading_chunks → cmKeepChunks / cmMappedChunks` 是实际消费者。AE 使用原生 `noBreak` 让短语整块换行，随后根据实测行推进。放不下时报告布局问题，禁止按字数硬切或自动缩小英文。
- `audit → validate_reading` 同时检查原生范围等于作者词块、noBreak、行覆盖、逐块峰值、返回和颜色衔接。此检查不能证明划分自然；词块编辑判断、实际观看与教学事实审阅分别记录。

首次运行 `chunks` 若缺作者划分，仅生成精确原文工作包并明确返回待编辑，不生成可制作的假划分。语言编辑不得改变 ANSWER 的证据、方法、选项及答案。回归见 `tests/test_article_chunking.py` 与 `tests/test_reading_review.py`。

已有工程或收据先核查，不重复 build。改变已原生执行的输入须另存修订。原生写入继续使用跨 worktree 的宿主占用、工程及目标身份回读；不重放未知结果的操作。未受影响的 take/渲染分段按真实依赖复用。默认每段 96 帧，实际 192 帧预览也已验证；20 秒扫读段曾触发内存保护，保留停止收据并检查队列后改为较小分段，不自动重试。

## FREE_SHOWCASE 方法表达

### 导演总原则

> 不按选项数量分配讲解篇幅，按判断困难和方法价值分配篇幅。显而易见的快速通过，真正困难的充分展示；所有精细动效优先服务于方法改变判断结果的瞬间。

原文同时记录在 [Video OS 导演总原则](../video-os.md#导演总原则)。作者安排每题口播、停留、动作和局部慢放时直接使用；完整核对保留必要依据和四项终判，不等于四项平均分配时长。这是导演取舍，不添加自动判断难度的教学推断器。

### 前台表达

默认采用**点名—执行—结果**。有效方法名就是压缩后的操作指令，在即将使用时直接说出或显示；第一视角的连续认知动作展示实际变化，配一句必要判断。同一方法再次出现时直接调用名称，不重复定义。本片采用冻结资料中的“跳读定位”和“换词不换义”，名称、触发与动作不超出已有来源；不把用户举例的名称自动当作新方法。

完整解题不要求完整讲解。Evidence、Action、Stop Rule、适用边界和四项终判仍在后台完整保留；前台保留决定性证据，删去逐段报行程、方法定义的复述和能被动作替代的解释。禁止默认把 Pedagogy / Student POV / Direction 的分析字段逐项做成口播或镜头。真正的理解障碍只补一句；全片只重点回看一个有实际价值的动作，其余按当前任务连贯执行。

本片继续让价格比较对象的回接承担唯一重点回看；“参加/主持”不再加入生活举例。压缩稿同时重算声音、字幕、注意力与判断时机，收紧重复停留，保留原位辨认和落稳阅读。不能把删掉的讲解换成等长静默，也不能用全局加速破坏已认可的动作质感。FREE_SHOWCASE 看高手调用方法产生结果；PAID_MASTERY 再展开条件、组合、边界、错误与迁移练习。实际观看评价方法是否能认出、变化是否能看懂，不用字段数量代签。
