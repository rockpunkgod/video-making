# 从 Opus 样片到整期：参考片驱动制作

适用：FREE_SHOWCASE 已有冻结教学资产，以用户认可的 Opus 实际样片建立整期表现标准。
这是现有作者、制作和审阅流程的编辑工作方式，不是新导演、渲染器或评分系统。
入口仍为 `ae/experiments/adaptive-episode/run.py`，沿用 `agent-jobs/creative_author`、
`AV_AUTHOR → AV_PLAN → authored_native → AE / Premiere → package` 与现有证据输出。

## 1. 先确认实际参考与范围

Codex 从生产索引、收据和实际文件核对 revision、工程、媒体 SHA、帧率、时长、声音及来源。
索引与实际新片不一致时记录差异，不用旧索引覆盖新成果。保留原件，在新 revision 制作。
参考必须是可播放的真实媒体，不以文字方案、模型名或静帧代替。
记录谁认可了哪个具体版本、认可范围和原话；认可一个镜头不等于批准全片或公开发布。

本次已知参考位置（仅供查找，不是所有机器必备的运行依赖）：

- 后续整期、AE 原生动效及字幕修正版有各自独立目录与收据，不相互冒名。

复用前重新计算实际文件 SHA 和规格，绑定实际来源、脚本、资产、完整音轨与身份声明。
本地路径不是已验证哈希，Opus 的自报模型名也不是提供方认证。

## 2. 从实际运动提炼标准，不照搬情节

作者原速观看参考，必要时回看连续区间并试听。将观察记在现有 `authoring_notes` /
`EDITORIAL_MANIFEST`：参考时间范围、看到的具体效果、拟迁移的原则、不能迁移的内容。
未完成观看或试听的维度明确为 PENDING，抽帧只能支持静态观察。

重点拆解以下相互配合的因素：

- 空间与材质：文字、物件、景深、遮挡、光照是否属于同一个可理解的世界。
- 动感：运动的准备、加速、尺度变化、镜头跟随、落稳及声音如何共同服务认知变化。
- 判断：观众在解释之前或同时，能从哪个具体画面事件发现关键关系。
- 连续性：原文从哪里来，注意力怎样跟上提取，比较后如何接回来源及下一场。
- 收益：这一事件让哪项困难变容易，画面是否仍需旁白才能成立。

不要把质感等同于加滤镜、光晕或阴影；不要把动感等同于增加位移、粒子或每字配音效。
允许物件和隐喻，但它们必须承担判断，不能退回图标轮播、静态关系树或文字卡讲解。
“把错误选项的后果拍出来”只是一个已用思路，不是通用模板。

## 3. 每道题独立找值得拍的认知事件

### 同类暗场画面的固定质感

当前权威参数为 `creative/motion-identity/display-identity.json`，实际 Canvas 文字/表面
消费者为同目录 `display-identity.js`。新 FREE_SHOWCASE creative_author 请求自动绑定
二者实际字节 SHA，不能只靠作者从旧聊天记住风格。作者把相应角色与参数映射到已有场景和
EDITORIAL_MANIFEST；Adobe 仍由现有原生文本/形状消费者执行，不新增渲染器。

暗场标题、结论、方法回收、品牌与参与提示统一中文字体、字距、冷白主字、低对比次信息、
细线与克制落稳。教学必要文字优先可读，不照抄品牌副标题的暗度。图标要有明确的描边、
转正或落稳动作，不给每一个标签加提示音。三连完成后退出，品牌独立收束。
原卷、原字、纸面及物理三维场景不是暗场文字卡，保留其来源字体、结构、材质和空间；
字幕仍按其辅助阅读职责排版。不要为了统一，把整片压成同一种黑底居中文字或全片滤镜。
只在对应 revision 的实际成片与参数读回确认后记为已消费，未覆盖的场景逐项列明。

Codex 提供冻结原题、方法、事实、选项核验和边界。作者决定每题最有价值的判断，使用
现有 `teaching_focus` 分配 quick / brief / focus，完整后台正确性不要求前台平均展示。
可采用关系对齐、身份揭示、范围改变、空间约束、真实过程重现或其他适合本题的表达。
视觉隐喻须与真实原句区分，不能增加事实、伪造捷径或提前把未成立的判断拍成答案。

第二题需要新的认知困难和独立收益，不能只换词、换图标、复刻第一题的动作顺序。
先对照标杆检查一个有完整转折的风险镜头，再扩展整期。用户已认可的参考可直接复用，
不要求每场、每段重新审批，也不为了证明流程重复渲染旧片。

## 4. 接回解题过程，形成整部作品

在真实题目上串起：痛点 Hook → 完整原题挑战 → 跳读定位 → 对应原句提取 → 关键认知事件
→ 有据判断 → 第二题的新困难与回报 → 方法回收及已授权的个人品牌结尾。
这是一条功能关系，不规定所有题必须使用同样镜头或相同时长。

- Hook 使用与正文一致的材质、空间和运动语言；痛点由实际方法与题目兑现。
- 当前 EP01 的挑战为每题 120 帧 / 24fps（5 秒），保留原卷标题、段落和表格、完整题干
  与选项，提示可暂停；保持中性，不泄露判断。其他题按作者与用户决定，不能强推固定长度。
- 复用已有搜索/意群/Reading Rig 能力。搜索命中与决定性证据要有不同的注意任务。
- 观众注意力跟上后，让来源绑定的原字连续进入比较；不能消失重生或只剩无来源的装饰字。
- 阅读与判断保留必要时间，删除无任务等待、独立重复慢放和为了凑片长的填充。
- 教学主体、注释、字幕和品牌各有层级；移除内部镜头编号、制作说明及未经授权的说明小字。
  必要的题源、阅读信息、字幕和素材署名不按“所有小字”一概删除。
- 当前 EP01 已由用户决定无口播，不再等待真人录音，也不生成替代配音；需要口播的其他
  项目继续走正式稿件审阅与真实录音交接。当前决定不自动改写其他项目的声音策略。
- 本片完整输出 3840×2160、24fps；预览可降分辨率，不能标为最终 4K。

## 5. 制作职责及实际消费者

默认：Opus 负责创意、镜头、动效及直接 Adobe 制作；Codex 负责事实、文案、素材、
底层支持、工程保护、验证与交付。用户后续明确让 Codex 改造某版时，记录该版授权，
按授权执行并如实署名，不冒充 Opus，不把单次例外改成默认职责。

关键决定写入现有作者场景、`cognitive_symbols`、`teaching_focus` 和 `EDITORIAL_MANIFEST`，
通过实际 AV_PLAN 与 Native 消费。无法表达时只扩展最小契约及原有消费者。
自定义脚本须保留输入、版本、命令、资源和重建入口；不能只有手改 AEP 而无法再生产。
不支持的创意返回具体限制、影响、替代损失和成本，由作者决定，不静默降级成 PPT。
Adobe 写入沿同一 HostOwnership 单写者保护，异常先核对，不盲目重试。

已有程序化片段不因未使用 AE 而改名为 AE 成果。用户要求 AE 优化时，应有真实原生
图层、相机或动作消费及编码媒体差异；仅将整段视频导入 AE 加滤镜不算镜头动效改造。

## 6. 音效默认使用 Csound，停用 Woosh

新制作与新音效返修使用 Csound 合成，不调用 Woosh 模型或复用其生成音效作为新版本音效。
保留历史音轨和凭证；迁移另建 revision，不能覆盖旧成片或抹除旧音效来源。

按现有音效事件 ID、画面事件 ID 和时间范围编写 `.csd` / orchestra / score，记录实际
Csound 版本、命令、输入参数、随机种子（如使用随机过程）、采样率、声道及输出 SHA。
单位明确：时间 ms 并保留帧号，合成频率 Hz、增益及包络使用对应真实单位。
先生成独立音效，再试听、调低噪声感或调整包络；低响度、低噪声底不能代替实际听感判断。
音效只强调有意义的结构变化，不给每个词配提示音，也不默认增加持续噪声或音乐底床。

替换已有 Woosh 混音时，从可核实的干净音乐/其他合法独立音轨重建，不能往含 Woosh 的
最终混音上叠 Csound 后宣称已移除。音乐与未变音轨按真实依赖复用，明确记录来源及权限。
库或外部采样的使用权单独核对，不把“Csound 生成”当作所有输入自动获授权。
若 Csound 不可用，报告具体依赖，不静默回退 Woosh。

复用现有声音事件、混音、Premiere 和 `audio_manifest`；不新增音效引擎或调度系统。
音乐、音效和必要字幕按同版时钟绑定。没有独立事件轨或精确时序时明确缺失，不能猜。

## 7. 以真实整片做对照和定向返修

审阅者对照参考和新片的实际连续媒体，至少检查 Hook、两题关键转折、跨题衔接和片尾。
逐项记：媒体 SHA、时间/帧范围、观众任务、可见问题、对应作者决定/消费者、修订与复验。
查材质与物件尺度是否一致、运动是否有认知作用、第二题是否仍像图标演示、来源是否可追踪、
镜头交接是否连贯、字幕是否遮挡主体、声音是否噪或抢读。不能只交接触表便称整片看过。

技术验证包括真实规格、完整解码、时间线、音轨、字幕/屏幕文字、工程及哈希的同版绑定。
复用自动 `review_evidence`，计划值、工程值、原生读回与成片实测分别标注。
实际原速观看、试听、手机阅读、独立审阅及用户验收分别登记；未做则 PENDING。
发现的确定缺陷先修再交；未观察或尚有创意不确定性如实写明，不包装成“已通过”。

渲染时遵循现有 AGENTS.md：Luna low 只读等待，主 Agent 整理证据，保持 Adobe 单写者。
交付完整可观看媒体、可编辑工程/可复现脚本、必要字幕及审阅入口，内部过程记录单独保存。
包装、标题或媒体更改使旧盲预测的适用范围终止，使用现有 AudienceLearning 另存新记录，
不回写冻结预测、不虚构受众效果。公开权限、用户最终认可与真实投稿仍是独立事项。

## 本流程的实施状态

本文件固化已实践的工作方式，并指定 Csound 为后续音效工具；不宣称历史影片已自动迁移、
新增原生参数已执行或感知审核已完成。每次执行以该 revision 的真实收据和实际媒体为准。
