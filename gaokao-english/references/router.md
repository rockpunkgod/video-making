# 请求路由

先按题面结构识别题型，再读对应模块。标题、年级、课程文件名和答案字母都不是路由依据。

完整文章后有 A 到 D 选择题，进入阅读理解。正文含五个空并提供 A 到 G 七个候选句，进入七选五。短文中有连续空位且每空配四个词项，进入完形。听力材料读本目录的 `listening.md`。

短文空位中部分带括号提示词，那是语法填空，不在本 Skill 范围，交给 `gaokao-grammar-fill`。要求续写两段且给出段首句，或要求书信、通知、演讲等短文，那是作文，交给 `gaokao-writing`。这两类都不要用本 Skill 的解题方法硬套。

请求类型分为讲具体题、纠正学生判断、解释方法、指定方法做题。无论哪种请求，都先检查该题型是否有激活方法，再检查触发与边界。请求范围还要区分整篇与单题。整篇按题型逐题构建实际触发方法集合，只调用对应模块的方法；单题按当前空或题干的触发条件处理。七选五整篇默认在开头统一按主体一致、时态一致、结构一致形成一次暂定分组，单题则在该题开头分组一次；分组要落到具体字母，没有可观察区别的维度如实说明。完成后按容易突破的空推进并回正文求证，不在后续逐空重新分组。

当前可执行阅读路由包括已激活的主客一致、同源替换、比较级谨慎选、过度推测、因果选果、并列删除、例子非答案、三化法、代词指代和逻辑简化。课程证据还支持跳读定位、积极阅读法中的名词定出处、题文同序、动词定逻辑，以及mainly题的主旨大意操作。定位阅读法是应用文阅读课程题名；顺藤摸瓜、左顾右盼、中心思想是8.7讲义各自独立原名。名称身份按阅读模块说明，调用只限已验动作，中心思想未验的常识推理不借mainly题流程激活。七选五、完形及其他题型路由保持不变。路由隔离是硬边界：阅读仅进入阅读模块，七选五仅进入七选五模块，完形仅进入完形模块。跨题型的同名词、首句、复现、主线或逻辑动作不能作为方法证据。

需要建立或核验阅读主题／展开框架时，可进入积极阅读法的“重复定主旨”受限小节。主旨、标题与段意先分清所问范围，再从共同／反复概念及关系、时间等线索形成待验预期，回所问正文核实际展开及完整候选覆盖；无有效重复不强做，不能只由次数或缺原词选排。它有独立课程名称与功能，不并成三化法别名，不改三化先题干与主旨选项、再有效首尾、再中间段首的入口，不新增文体专属或四项必联用流程。

阅读褒贬一致已验为可调用的标题/段意候选比较判据；秋03另验到对象评价／内容判断、认知因果解释、词义方向筛选三个有限入口。当前题须有同一对象、所问范围及可比较的方向差异才进入阅读模块对应小节，方向初筛后回文核完整否定、限定、对象、关系与候选具体含义，正向支持才定案；学生点名演示时也检查各入口触发条件。复杂作者态度、混合来源及同向细义仍按缺口处理，不借积极阅读褒贬定态度的验收，也不改变题序或三化核验。

题干问作者对某对象或观点的倾向／评价，且有可确认的作者评价时，进入积极阅读法“褒贬定态度”受限小节：对齐所问对象／方面和评价来源，核完整情感评价及否定、条件与必要上下文，再比较方向和当前具体含义并求正向支持。方向只缩小，完整批评关系可支持对应评价；来源或细义缺证据才停止，不整体拒绝已证观察。作者建议、标题／段意方向比较与人物评价不冒充作者倾向；复杂来源、反讽与同向细义模型仍不扩，不能由实现未定推出态度模糊，不另加固定四项流程或题序。

阅读模块分工两层。入口层按文体给优先顺序，帮学生省下逐题判断任务的开销：A 篇这类应用文先按定位入口走，B 篇这类记叙文先按事件线走，C、D 篇这类说明文议论文先按主旨走。主旨类任务进入三化法时，先读题干和主旨题选项形成假设，再看有效首尾段，最后看中间段首句；重复词缺失时跳过该观察，仍完成首尾和段首核验。调用层按题面实际问什么来定：需要快速回原文找对应位置时用跳读定位及名词定出处、题文同序；需要核前后关系时用动词定逻辑和必要上下文；全文或段落主旨题按mainly题操作，需要建立或验证全文主题、态度、结构或框架时调用三化法，按阅读模块的触发与边界执行；选项是否遗漏核心主旨，在该题所问范围内核对，属于排除理由，不另调用“主旨缺失”方法。主客、同源、比较、过度推测、因果、并列、例子、代词和逻辑简化均按各自题面触发条件调用。

入口层只是做题优先顺序，不是课程规定的方法对照表；当前已激活的通用阅读方法没有覆盖全部文体与题型的完整专属表，两层冲突时先判题面任务，并遵守所调用方法已经确认的专项文体与题型范围。课程记叙文主旨概括四法中，首段法、合并法、首尾呼应法已有受限操作，核心名词法已有反复主题对象→待验框架→回文核对的辅助：只在记叙文全文主旨／标题任务进入阅读模块对应小节，不扩成所有记叙题入口，不另排四法固定顺序，不改变全篇题序或三化入口。核心名词可由反复原词或可确认同义主题表达进入，当前词义、所指或覆盖不明时按具体缺口求证，不要求前置逐段扫描或计频；学生点名已验操作时不整体拒绝，也不补成完整四法，不将核心名词法并为重复定主旨别名。顺藤摸瓜、左顾右盼按记叙细节的各自已验线索使用；分句结构法按三步结构职责受限调用，不能删答题相关修饰。课程题名与原名不能直接扩大为其他文体或任务的算法。

完形方法问答及指定方法请求进入完形模块的对应受限小节：三读解释初读、细读、复读的原职责，不强制作答遍数或宣称与固定遍数一一映射；角色渗透在当前候选依赖视角、行动或感受归属时核当前人物与阶段；同根复现仅用已知可确认派生关系查线索；大词／大小原则仅核实际竞争的宽泛与具体属性差异。主被动、主语与褒贬一致按已有施受、行动归属及形副方向检查解释，不借其他题型同名规则，不因尚缺完整独立算法整体拒绝已证职责或动作。各项按触发需要调用，证据不足暂留，不强制固定空号或两遍作答，最终回填核查保留。

学生指定的方法若不存在、未激活、与题型不匹配或越过禁用条件，直接说明不能按该方法可靠处理，不得默默换方法。判断名称未覆盖前先查`evidence-gaps.md`的待验收登记；课程已有定义而本 Skill 未激活，不等于课程没有该方法。

学生点名的是判项标签、篇章主题词、记忆比喻或系列名称时，按该名称在对应题型中实际承担的功能路由。先把它说明为具体的对象、关系、范围或定位检查；已有已核验动作就解释该动作，未验收动作才说明缺口。主旨缺失继续表示候选没有覆盖所问核心内容，进入相应主旨覆盖核对，不因课程另有专门说明页而重新注册独立算法。图像辅助定位和范围核验分别处理，不因相邻讲授就合并为一个方法。
