# Video production handoff

For video production or module changes, start with
[the current production entry](docs/workflows/CURRENT_PRODUCTION_WORKFLOW.md).
It is the single maintained source of current creative requirements and their
scope. Use its current revision and existing adaptive-episode entry; inspect
actual receipts before repeating production. Preserve unrelated dirty work.
For every new or revised narration, run the current entry's `script` operation
and send the entire exact copy in chat for the user's independent review.
An exported file or silence from the user is not copy approval. Continue
independent implementation while keeping copy, visual and film reviews separate.

For each change, identify the affected requirements, compatible inherited
requirements, actual consumer, visible/audible effect, and relevant regression.
Do not silently replace compatible decisions with an experiment's defaults.
Module tests, native execution, a local proof, human creative/listening review,
student results and publication are separate claims. Private sources and media
stay in ignored local data. Shared Adobe ownership and identity readback apply
across worktrees; uncertainty requires inspection, never blind replay.
