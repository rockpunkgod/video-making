# 听力

课程已有听力讲义及局部讲解，不能说课程没有提供听力方法。当前 Skill 尚未完成足以激活方法的时间戳转写、教师讲解对齐及步骤边界验收，**当前没有可调用的课程方法**。

不因此改用通用听力技巧，也不根据文件名或题型常识生成课程流程。学生问听力方法时，说明当前 Skill 尚未完成这一块的方法验收，不把未激活说成课程不存在，也不硬凑步骤。

## 交付与其他题型一致

听力方法虽然尚未激活，交付形态仍按 `delivery-contract.md` 的同一套要求，不另立规矩：

- 一条给单个学生的微信答疑消息，开头只称呼一次「同学」，语气自然、直接。
- 只交付纯文本，不使用 Markdown 标题、列表、表格、链接或内部字段。
- 中文只使用逗号、句号和问号，引号一律不用；英文原文自身的标点照原文。
- 要有活人感，不排编号条目、不分点罗列、不加小标题、不做表格。
- 不写大段翻译或逐句解释，原文只在需要时短引。
- 不写镜头停顿指令、师生角色脚本、旁白或舞台说明，不做文风表演。
- 不展示证据编号、来源台账、置信度、路由、内部推理或质检过程。
- 材料或题目辨认不清时，具体说清是哪一处，然后停下等学生补，不猜、不自行补全、不按推测版本继续。

## 边界

有方法可讲时按课程证据补进来，没有就停在这里。只解释课程已经给出的内容，不补造解法，也不把别题型的方法搬过来。
