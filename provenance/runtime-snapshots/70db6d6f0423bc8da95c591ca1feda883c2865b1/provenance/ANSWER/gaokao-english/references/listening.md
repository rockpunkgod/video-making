# 听力

本模块支持已核课程“解题三步”的练习／精听职责及下列训练、助记原名。已验为有界代表，不是全听力课程、所有考试题型的完整算法验收；不可继续以“没有可调用方法”整体拒绝，也不把训练流程套成正式考试的重听流程。

## 解题三步（寒13练习／精听来源）

先检索题目、画重点并简要理解其含义；第一遍重点锁答案出处和可能考点，不急于定案；再仔细比对文本与选项，尽可能核清另两项哪里不成立。第二步“不先确定”属于本课可回放精听条件，正式一遍制短对话须在实际播放次数内作答，不能要求等不存在的第二遍。

实际核对要落到同一人物及其动作、对象、时间、条件和真实诉求，听见相同词不代表完整选项成立；近义改写也不因缺原词排除。说话人、被提及者和替别人办事者分开，否定作用于完整动作关系，愿望、现象与原因分开核。排掉两项仍须给所选项的正向录音依据。没有音频或可靠原文时说明缺口，不假装已听见；课程没有独立命名的这些操作只说明实际内容，不自创技巧名或借阅读同名法。

## 因病转低保（听力助记）

本课原字为因病转低保，记因果、并列、转折、递进、包含五类关系。预看选项的名词、动作、方向及限定，形成待听差异，再以原音完整关系核证；不是五步固定顺序，不凭only、褒贬或转折词猜答案，不借七选五同名的顺序。

## 训练原名分别保留

- 挖空听：反复听当前句、补实际听到的词并核对，服务听辨，不是考试无限重放权限。
- 连读练习：跟原音练当前句的连读、弱读与完整发音，再逐步加速，不从机器转写臆造细微音标。
- 盲听：本课不看题先记信息，再看题答；这是训练条件，不能强制正式考试放弃预读。
- 倍速精听法：据听辨情况调整速度、反复核难句，具体倍速不固定成所有学生门槛。
- 影子跟读法：尽量贴原音跟读。暑02原课分0.8–1倍看文本、1倍脱稿、1–1.5倍脱稿三个递进阶段，跟上且发音完整再脱稿／提速，非只做三遍，每阶段可多练；不是选项判据。

春09“听力训练第一步／第二步／第三步”是另一来源的分层安排，名称及职责保留，不并入寒13解题三步。第一步面向125+还想练习者，三遍依次为不看题选项记人和动作、看题盲听记可能答案、看题看选项核答案；第二步向错6个以上者建议错题分句精听，原课每段不超5秒、反复5–10次以内；第三步影子跟读，最高要求脱稿跟音。分数、时长和遍数为本课建议，非所有人统一考场步骤或提分保证。

## 交付与其他题型一致

听力交付形态按 `delivery-contract.md` 的同一套要求：

- 一条给单个学生的微信答疑消息，开头只称呼一次「同学」，语气自然、直接。
- 只交付纯文本，不使用 Markdown 标题、列表、表格、链接或内部字段。
- 中文只使用逗号、句号和问号，引号一律不用；英文原文自身的标点照原文。
- 要有活人感，不排编号条目、不分点罗列、不加小标题、不做表格。
- 不写大段翻译或逐句解释，原文只在需要时短引。
- 不写镜头停顿指令、师生角色脚本、旁白或舞台说明，不做文风表演。
- 不展示证据编号、来源台账、置信度、路由、内部推理或质检过程。
- 材料或题目辨认不清时，具体说清是哪一处，然后停下等学生补，不猜、不自行补全、不按推测版本继续。

## 边界

学生问解题时只调用当前条件能执行的已验职责，问训练时说明训练对象和进阶条件，问黑话时解释实际记什么。只讲已核范围，未覆盖情形说明具体缺口，不补造流程，不把别题型同名方法搬过来。来源见`course-evidence.md`的2026-10-30增量登记。
