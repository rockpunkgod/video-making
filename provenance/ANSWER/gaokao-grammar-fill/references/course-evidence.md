# 客观题课程取证入口

四类题型已核实的操作要点写在各自模块，不必每题读本文件。仅在追问“课程怎么说”、方法归属不明、发现版本差异或模块未覆盖时使用。本文不是新题型，也不改变两类作文。

## 如何使用新问答包

若同级存在 `kaiming-english-qa`，先读取它的 `SKILL.md`，再在该包目录使用 `python scripts/library.py search 关键词 --limit 12`，或直接搜索 `references/corpus`。读取命中的完整相关段落，不拿检索摘要作结论。下列 ID 对应 `references/corpus/ID.txt`，讲义全名、原件与质量提示见该包 `references/catalog.json`。

涉及导图、手写或乱码时，同时读该包 `references/visual-recovery.md` 与对应原图/原件。补录是人工概述，不是无误逐字稿。该包不存在时，已写入本技能的规则仍可用；额外课程问题向用户索取相应讲义，不依赖固定电脑路径、不自动联网安装，也不声称已查看不存在的资料。

来源优先核对明确勘误，其次核对题干、例句、解析是否属于同一题。区分课程原话、对课程的操作整理和基础语法解释。发现课件分类简写或解析错误，不照抄成普遍规则；需要用户决定的教学取舍，列出具体矛盾再询问。来源检索与内部检查不写进学生口播；用户问出处时才自然说明讲义、章节、页或题。
