# 应用文写作与批改

本文件只用于应用文，不能用于读后续写。题型识别只做内部路由，交付稿不要复述“这是应用文”或展示判断过程。

## 使用边界

- 写作指导至少需要题目；批改最好同时有题目、学生全文和清晰的书写图片或转写文本。
- 缺少题目时，只能校对语言和大致结构，不能判断要点是否齐全，也不能给完整分数。
- 书写、格式和字数只能依据实际可见内容判断；看不清时标记“不确定”，不要猜。
- 先按评分标准判断档次，再给分。课程方法用于诊断和训练，不得冒充官方独立扣分项。

## 15 分评分规范

先从内容组织、词汇语法、篇章结构三方面看整体完成度，以 9 分为是否基本完成任务的参考线，再在对应档次内综合定分。

| 档次 | 分数 | 判断要点 |
|---|---:|---|
| 第五档 | 13–15 | 覆盖全部要点，表达清楚合理；较多恰当的复杂结构和词汇；错误很少且不影响理解；衔接有效，结构清晰，完全达到交际目的 |
| 第四档 | 10–12 | 基本覆盖全部要点；语言能满足任务，少量尝试复杂表达造成的错误不影响理解；结构紧凑，达到交际目的 |
| 第三档 | 7–9 | 覆盖主要内容，可能遗漏次要点；语言基本够用且句式有一定变化；部分错误不影响理解；有简单衔接，基本达意 |
| 第二档 | 4–6 | 漏掉或未说清部分主要内容，夹有无关内容；结构单调、词汇有限；错误影响理解；衔接少，信息传达不清 |
| 第一档 | 1–3 | 明显遗漏主要内容或偏题；多处错误导致词不达意；缺少衔接，信息未能传达 |
| 0 分档 | 0 | 未作答、内容太少或无法辨认，或与题目完全无关 |

附加规则：

- 词数少于 60 或多于 100，从总分中减 2 分。
- 拼写和标点按其对交际的影响处理；英式、美式拼写和词汇用法均可接受。
- 书写差到影响交际时，降低一个档次。只有看到原始书写时才能使用这一条。

### 书写评价边界

- 书写只评价“是否已经影响交际”，不单独评价美观程度，也不设置卷面美观分、字体分或书法式等级。
- 只有提供清晰的原始手写作文图片时才评价书写；转写文本、键入文本或无法看清的图片不作判断。
- “影响交际”是指部分单词、字母或信息无法可靠辨认，已经妨碍阅卷者理解文章；仅仅不够漂亮、个人不喜欢某种字体或一般性的书写差异，不触发降档。
- 确认影响交际时，先按文章内容、语言和结构确定原始档次，再依规范降低一个档次，并指出造成辨认困难的实际位置。没有影响交际时，不因书写另行降档。
- 反馈只需简短说明，例如：“原稿中___处较难辨认，已经影响信息传达；建议书写时优先保证字母和单词能够清楚区分。”不要输出额外的美观度评分或超出规范的书写训练量表。

## 批改顺序：先五审法

批改须细致覆盖写作思路和语法两个层面。先结合五审法、单句锚定和模块组篇，检查学生怎样理解任务、安排要点、展开理由及细节、组织段落和回应写作目的。每个思路问题指出题面要求、原稿位置、具体欠缺和可直接落实的补写或重排示例；对成立但可改进的内容，解释怎样更具体、连贯或得体。随后逐句检查语法，包括句子主干、谓语与非谓语、时态语态、主谓一致、从句连接、人称指代、单复数、冠词、介词和词性，并检查搭配、拼写和标点。逐处给出原句、保留原意的改句及原因；重复错误可以合并讲规则，但各处改法不能遗漏。概括重点不限制纠错数量；正确句子无需硬改，可选润色与确定错误要说清区别。按总入口要求用纯文本自然段呈现。

严格先框架、后语言。依次完成五审，先指出会影响档次的问题，再处理局部语法。

1. 审文体：核清是否满足题目要求的格式。书信或邮件核对称呼、正文和落款；通知核对标题、正文、落款及日期是否按题面要求；演讲核对称呼、开场主题和致谢；报道核对标题及事件信息。
2. 审对象：确认写给谁、双方关系和作者身份，检查称呼、语气、礼貌程度和正式度是否匹配。
3. 审要点：逐条列出题面明示要点和隐藏限定，如身份、时间、地点、参与者、目的、活动内容、注意事项或写作对象；标记“已覆盖、覆盖不充分、遗漏、偏离”，不把自行脑补的信息算作完成要点。
4. 审逻辑：核对开头是否交代目的，主体是否按一个段落或模块只完成一个核心任务，结尾是否回应交际目的；过渡是否自然，是否存在重复、跳跃或因果不成立。
5. 审语言：最后才查人称、时态、主谓一致、名词单复数、词性、介词、搭配、拼写和标点；区分“影响理解”和“不影响理解”的错误。

## 开明致学写作方法

### 应用文写作六步训练法通用梳理框架

1. 精准审题：完成五审，先圈限定词和全部要点。
2. 模板套用：按文体搭出开头、主体、结尾的基础骨架；模板只保结构，不机械照抄不合语境的句子。
3. 单句锚定：按“锚定主体 → 锁定动作或状态 → 嵌入时间、地点、原因等细节”先造准确的简单句。
4. 模块组篇：把内容分成 3–4 个逻辑模块，坚持一个动作或信息一个模块；再用连接词、从句、非谓语或介词短语自然粘连。可用“反向劫匪插葱”检查复杂句的主干和修饰成分。
5. 优化升级：框架完整且基础句准确后，再替换更具体、得体的动词和词组，适量加入复合句、非谓语等；不为高级而生硬堆词。
6. 检查复盘：逐条复核要点、格式、时态、人称、主谓一致、单复数、拼写、标点和词数；把本次高频错误变成一条可复练规则。

### 三种写作表达方法

- 基础句式锚定法：主体 → 动作或状态 → 场景细节。先保证句子成立。
- 复杂句式模块法：把中文拆成若干动作模块，每个模块先写成正确简单句，再按真实逻辑用从句、非谓语或连接词合并。
- 长句翻译重构法：先区分核心信息和修饰信息，再按英文“主体 → 核心动作 → 场景或伴随”的语序重组；最后校准时态、词性、单复数和风格。

### 富兰克林写作法（寒4五步）

课后训练先简化中文（原句已简单可直接译）→译成英文→对照范文→记录并背诵自己缺的词或句式；想进一步提高时，可选用 AI 升级词和句型。这是寒4原课五步，末步为可选进阶。挖空法是另一项独立的填空、对照、纠错训练；不能将旧整理的六步循环称为本课原定义。批改交付只挑最能解决当前问题的句子示范。

同名的赠44、赠47、暑13及国庆来源另有挖空或中文提示回忆、对照错漏的训练版本；按所问来源说明，不把这些形式强塞进寒4五步，也不因使用同名就删除其训练身份。赠44还明称**富兰克林作文法**，操作为看中文补英文缺口→对照原英文、重点记错漏→熟读后重新遮空填写→再对照补缺；**刻意训练**是该循环的训练称呼。与范文不同但正确的表达不能仅因不一样而判错，原例语言错误不复制为目标句。

### 句子写作思路

原讲义五项句子组织提示：确认动词→谓语／非谓语（从句）→主动／被动→句型→描述成分。表达内容已明确而需组织或检查句子时，按这些依赖处理当前句；词义、施受及修饰必须符合当前语境。这不是另一套五定法，也不替换三种写作表达方法或强制每句升级复杂结构。

### 个人--家庭--学校--社会

赠48原板书的开放要点构思提示。题目没有明确具体要点、需要想事件意义或自己能做什么时，可从这些实际相关层面寻找内容，再按题目目的筛选；题面具体要点优先。不是固定每题三点／四点，也不要求逐层各写一段。该源“写三圈”机器识词仍未核字；27S暑讲义另有清楚原名“大小三圈”，见下方独立小节，不能据新源反改旧机器稿或将两个名称合并。

赠49另从“自我—学校—社会”找评价和意义的相关角度，学校可含同学、老师；能把两点说充实也可只写两点。保该来源角度提示，不覆盖赠48的四层或27S暑的大小三圈，不为凑点数给每个动作强加升华。

### 总分总的呼应

赠45感谢信的课堂结构称呼，开头感谢、主体说明相关帮助与影响、末尾再次致谢，核首尾是否回应同一交际目的。按当前感谢任务使用，不作所有书信的统一骨架或新增评分项。

## 常见文体骨架

- 书信或邮件：根据关系做问候或自我介绍并点明目的 → 完成题目核心内容并适当拓展 → 期待、祝愿或回复请求。按写作意图可内部归为求人型、帮人型、传情型，但不要把分类说明写进交付稿。
- 邀请：邀请目的 → 时间、地点、活动及意义 → 期待参加或回复。
- 建议：表示理解或关心并点明目的 → 每条建议配一个具体做法或益处 → 希望采纳并祝愿。建议必须可执行，不能只喊口号。
- 感谢：明确感谢 → 用具体事件说明对方帮助及影响 → 再次致谢或表达回报意愿。
- 通知或告知：写作目的 → 时间、地点、参与者、活动内容和注意事项 → 必要的提醒、期待或联系方式。
- 演讲：得体称呼和主题 → 分层陈述观点、理由或行动 → 概括、呼吁并致谢。正式场合使用正式书面语。
- 活动报道：时间、地点、目的和参与者 → 按时间或事件顺序写过程 → 评价、反响或感悟。语言具体、简明、通俗，意义要由真实活动细节推出。

## 细节与升级原则

- 题目允许适当拓展时，补充能服务要点的动作、场景、结果或感受；不添加与主题无关的故事。
- 描写经历可从动作、心理和环境中选最有用的细节；不要每句都堆修饰。
- 先客观内容，后主观感受；“感悟”要落到理解或道理，不等于只写喜怒哀乐。
- 高级替换必须自然、准确、符合对象和文体。能清楚表达的常用词优于生僻但搭配不当的词。

## 应用文批改反馈话术

话术要像老师在和学生一起复盘，而不是宣读评分条款。保持亲切，但判断必须明确；每一句评价都要能在题目或学生原稿中找到依据。下面的句式是可替换的表达支架，不要逐句机械照抄。

### 话术节奏

1. 先肯定一个真实行为或结果：优先肯定圈画关键词、格式意识、要点覆盖、段落安排、表达得体或某个准确句子，并说清它为什么好。
2. 用一句话说清主要问题：先讲最影响任务完成度和档次的格式、对象、要点或主题问题，不要一开口就罗列语法错误。
3. 把问题落到题面和原稿：指出“题目要求什么、学生写了什么、还缺什么”，随后给一个能直接落笔的补法。
4. 再处理语言：逐句检查并指出能够确认的语法、搭配和拼写问题，优先解释影响理解或反复出现的错误，再补齐其余明确错误，采用原句、改法及规则相连的具体反馈。
5. 用一个下一步任务收尾：让学生下次只重点执行一项动作，如列要点、补益处、检查正式语体或自查三类错误。

### 各环节可用话术

**开场与真实肯定**

- “同学你好，咱们先看这篇作文。你在写之前有先圈出___，这个习惯很好，说明你已经在主动抓题目的限制条件，继续保持。”
- “先肯定一下，你把___交代得比较清楚，尤其是原文中的‘___’，已经起到了___的作用。”
- “这篇文章不是没有内容，你已经完成了___。现在要做的是把___补完整，让这些内容真正服务写作目的。”

不要只说“写得不错”“基础很好”。如果看不到圈画、书写或构思过程，就不能虚构这类优点。

**总体判断与改进优先级**

- “整体来看，文章已经完成了___，目前最影响得分的不是词汇够不够高级，而是___。我们先把这一层修好，再升级句子。”
- “这篇文章能让读者大致明白你的意思，但___还没有说清，所以交际目的只完成了一部分。”
- “主要问题集中在___和___。其中先改___，因为它会直接影响要点覆盖或文体任务；其他语言问题放在后面处理。”

**格式与写作对象**

- “先看格式。题目要求的是___，因此需要有___。你现在的___不符合这一文体的规范，建议改成___。”
- “这里的读者是___，你和对方的关系是___，所以语气要___。‘___’偏口语化／过于生硬，可以改成‘___’，会更符合交际对象。”
- “格式不是装饰，它也是任务的一部分。把___补上，读者才能一眼看出文章的用途。”

**要点、主题与拓展**

- “题目一共要求___个要点：___、___、___。你已经写到___；___写得还不充分；___目前遗漏了。可以在___后补一句‘___’。”
- “这里需要回到题目。题目围绕___，所以内容应集中在___。你写的___虽然能成句，但和核心任务联系不紧，建议换成___。”
- “这部分不要靠自己脑补新的活动或背景。先把题面给出的要点全部落地，再做少量合理拓展。”
- “这条建议现在只有‘做什么’，还缺‘为什么有用’。可以接着补___，这样建议就从一句口号变成了可执行的方法。”
- “开头只写___还比较笼统，可以补一个具体影响，例如___；结尾也不要突然喊口号，要回应前文的建议或写作目的。”

**逻辑与段落**

- “你的信息基本都有，但顺序有些散。建议按‘写作目的 → ___ → ___ → 期待或提醒’重排，读者会更容易跟上。”
- “这一段同时写了___和___两个任务，连接比较突然。可以把___单独成句，再用___说明二者关系。”
- “从___直接跳到___，中间缺少原因或结果。补一句___，逻辑就能接上。”

**语言纠错与升级**

- “框架确认后，我们最后看语言。原句‘___’中，___有问题；改成‘___’。这里记住：___。”
- “这个错误不只是词不够高级，而是___搭配不成立。先改准确，再考虑替换表达。”
- “这一句意思是对的，可以保留主干，只把___改成___；不用整句推翻。”
- “同类错误出现了几次，咱们合在一起记：___。写完后专门检查___即可。”

**总结与训练引导**

- “整体上，你已经能把___写出来，下一步重点不是背更多模板，而是写前先列出___，写后逐项核对。这个动作做好，文章会稳定很多。”
- “这次先抓一个最重要的训练：每条建议后补一个具体益处。你可以把原文中的___改写一遍，检查是否回答了‘怎么做、有什么用’。”
- “这些问题是可以通过固定自查解决的。下次写完先查___、___、___，再看词汇升级，不需要一次把所有地方都改复杂。”

### 话术使用禁忌

- 不把评分标准整段念给学生，不连续堆“遗漏、偏题、错误”等标签；先说明证据，再说明影响和补法。
- 不机械累计“这里扣 1 分、那里扣 2 分”。先按整体表现定档；只有评分依据充分时，才说明某类问题可能影响档次或分数区间。
- 不用“你不会审题”“基础太差”等给学生定性。可说“这次在___处出现了偏差”“下次用___核对”。
- 不为了安慰而弱化关键问题，也不以高考倒计时制造焦虑。鼓励必须落在已经做到的事和下一步可完成的动作上。
- 不把参考修改稿当成唯一答案。告诉学生为什么这样改，并保留其原意和能用的句子。

## 26S 讲义新增内容

以下保留 26S 不同课次的名称和训练说法。与上文不一致处按各自来源和适用范围判断，不按出现先后自动覆盖。

### 复习路径与分数锚定

**读-背-仿三步走**：读英文，熟读至背诵；背中文，背大致含义；仿写，走富兰克林写作法。

**分数锚定策略**：课程以基础模板用稳作中等分段训练锚点，再练三种写作表达方法；这不是保证分数或独立评分项。

**作文练习的顺序四阶段**：①写作模板（中文思路的记忆和简单英文的翻译）②八十个金句（基本句子和词汇素材的积累）③挑战高分（九大句型和高级词语）④冲击满分（两简一复从和句式重构）。

### 五审法的审核维度表

审文体：明确体裁（书信、倡议、演讲、图表），确认匹配的模板框架。审对象：确定交际对象（朋友、老师、教授、公众），据此调整语气与称呼。审要点：逐一核对题目要求的内容，如建议信三条建议、邀请信的时间地点活动。审逻辑：检查是否符合模板框架（“现象—分析—建议”“问候—核心内容—祝福”），过渡词是否自然。审语言：核查时态一致、无重大语法错误，替换基础词汇提升质感。

操作细节：圈出题目中的限定词，如“因病休假”要强调健康、“来自爱尔兰”可提及距离或时差。

### 三种写作表达方法的细化

基础句式锚定法：锚定核心主体，锁定动作或状态（含系表结构），嵌入场景细节（时间、地点）。讲义标注为“小学语文造句”。

复杂句式模块法：先有准确的主干简单句，再把相关动作各写成简单句，按真实逻辑用从句、非谓语、连接词或介词短语粘连。寒4徒步例中的“两简一复从”是主干之后加两个相关简单句再合成复杂表达的扩句训练，不是整篇句数或从句配额。

两简一复从的国庆来源另存：第1讲以当前只有两句为由说用不上，第2讲却用此名指两句信息合并。两处名称使用范围有张力，不能统一成两句必可或必不可。讲当前句子时保主句谓语，按实际关系把另一信息作修饰或从句；被问该原名时说明来源，不借续写寒14定义消除应用文异文。

国庆第5讲另有完整原名**两简一复从模版**，是单句组合训练：①围绕同一主题造三个简单句，课上建议其中一句用被动，以便后续转为过去分词，非必需配额；②给第三句加相关形容词、介词短语和状语从句；③以第三句结尾处的词作主语，再造一个表达相关信息的简单句；④把该信息接回第三句，形成定语从句；⑤将前两句转成非谓语状语，与升级后的第三句整合。现场也允许熟练时直接成句、判断不需定语从句时省去该扩展，考试按当前内容和表达能力选取部分结构。保信息关系与逻辑主语，不为凑主动、被动或超长句增加事实；原例修饰归属含糊和搭配问题不照搬。不与寒4长句翻译重构法合名，也不抹掉国庆第1／2讲的称名张力。

长句翻译重构法：语义解构（拆语义单元，识别核心信息与修饰信息）；语序重组（先定主体、核心动作与伴随成分，以此选择主要句型，再匹配可用句型与词汇）；细节校准（时态、词性、单复数）；风格统一（按逻辑优化衔接）。课程提到的 110／120 是当时能力或分数目标下的粗略训练分流，不能写成整篇词数阈值；看信息复杂度和学生表达能力选法。寒4徒步与音乐邀请两个独立单句材料均补核连续重构链，后者明确按信息角色分前置动作、方式修饰和主句，成句后回查介词、单复数；不把该例的完成分词框架固定到新题。熟练可直接成句、难扩展可省，不强制每次外显全部中间草稿，也不以长句或高阶词本身计分；不宣称两个材料已覆盖所有陌生题情境。

### 富兰克林写作法（五步）

①把中文简化，去掉不必要的修饰 ②翻译成英文 ③对照范文 ④背诵自己缺失的词或句式 ⑤想进一步提高时可让 AI 帮忙升级单词和句型。中英填空可作练习形式，但“挖空法”另有独立原名，不合并为五步的固定一步。

### 反向劫匪插葱

寒4在扩句示范中以此称呼把已写出的相关简单句拆组、拼贴；画面列从句、非谓语、介词短语三类粘连方式。按实际语义选用，不能按口诀逐字拆出固定步骤或固定先后，也不能把此处定义借给续写同名法。

### 三类高频书信的模板结构

邀请信属求人型，建议信属帮人型，感谢信属传情型。每类都按“常用表达（发出邀请、活动安排及意义、望应邀盼回复等功能块）→ 黄金模板（基本模板加升级模板）→ 仿写实操（题材、人称时态语气、要点分段）”。

建议信升级模板把三条建议分别用祈使句、定语从句、条件状语从句，一条建议一种句型。感谢信升级模板结构：感谢内容 → 背景 → 具体回忆 → 再次致谢 → 祝愿。

### 写人类（人物介绍）文体方法

人物介绍可核四类内容：基本身份（姓名、职业、国籍）→ 突出成就（主要贡献、典型事迹、荣誉）→ 个人品质（性格、精神品质）→ 社会影响（对他人或社会的积极意义）。“四件套”为整理便称，并非已核课程原名；依题目选择相关内容。

结构：开头段概括引入（人物重要性加核心特质）；主体段按**时间轴**（早期经历、关键事件、当前成就）或按**品质加事例**（Trait 1 加 Example 1，Trait 2 加 Example 2）分层展开；结尾段总结评价（精神传承或学习意义）。

人称时态：第三人称客观视角；现有人物用一般现在时写成就、一般过去时写早年经历；历史人物用一般过去时。

定语从句、分词结构、强调句是本课的句式素材；“三件套”为整理便称，按表达需要选用。

典型错误：信息堆砌、主次颠倒（过度描写外貌忽略品质）、时态混乱（He is born in 1950）。要避免主观评价，把 I think he is the greatest 改成 He is widely recognized as...。中文姓名拼写要正确（Zhang Guimei，不是 Zhang Gui Mei）。

备考：建立“人物档案库”，按科学家、运动员、文化名人分类整理中英双语素材；背诵万能评价句；做同一人物 50 词与 100 词的对比练习。临场快速列提纲，确定三个核心品质及对应事例；避免复杂生词，用准确代替华丽；结尾用名言或比喻升华。

**人物介绍评分口诀（内部记忆，口播不念）**：身份成就需分明，事例品质紧相承，数据细节增可信，精神升华得高分。

### 投稿类的身份与时态定调

前三步骤：①审题判定文体为投稿 ②因文体是投稿，作者身份在正文中不必交代 ③因主体部分是介绍人物生平事迹，全文总体时态定为一般过去时，首尾两段用一般现在时。三段论：第一段列举并引出人物；第二段人物简介及事迹；第三段启示。

### 活动类的三段式与散点技巧

三段式：首段目的 → 中段活动具体内容 → 尾段邀请信（期待回复）或其他（活动意义）。

检查顺序：审题和时态 → 三段式 → 逻辑词 → 段落内 → 三段话 → 词汇和句型升级 → 书面和检查语法。

**逻辑补充句**：首段末尾加一句承上启下句，四种变体——Here are some details about this exciting event. / Here are the details of this meaningful event. / Here are some highlights of this event. / Here are some fascinating aspects of this event.

课程曾用 `What we anticipate most is...` 和 `not only...but also` 示范表达重点；须先核语义与文体是否合适，不把单题示例设为每篇必用句型。

**语料标注约定**：蓝色用于扩充语料，绿色标重点词汇或短语；“必须背、必须使用”为该课训练安排，不作陌生题写作或评分硬要求。

**好作文的检查点**：审题（是否偏题、信息点是否缺失）、格式、考点信息；句型和词汇的丰富度；句子不够丰富时用细节例子补充；卷面工整。卷面是**训练目标**，评分仍按书写评价边界执行，不因字体美观给分或扣分。

### 写作误区与提分技巧

常见误区：结构混乱（混合段落）、要点遗漏、语言过度口语化（I miss you a lot! 应改具体化表达）。

提分做法：审题精准（圈限定词）、细节填充（添加符合校园情境的事件）、文化礼仪（对外教用礼貌用语）、句式多样（复合句）、结尾技巧（暗示未来互动，如 Looking forward to your early return! 比 Good luck! 更具期待性）。

范例改进法：把笼统句改具体——“Are you better now? We miss you.”改为“I hope your health has improved since your return to Ireland. It’s such a pity you couldn’t attend the recent cultural exchange day—your advice was greatly missed!”

### 26S春 补充

**三段话格式**（春5演讲示范）：①补全除题面明确考点外仍需交代的背景或主题 ②完成具体要点 ③按交际目的收束，最好扣主题。给几个要点就完成几个，不移用其他题的三理由配额；已给标题、首尾如何抄写按题目要求，不以该示范统一规定。

**保留格式抄原文**：春5现场口诀，保所练句型骨架，取题面或标题核心词，再按交际目的换词和补连接。不是逐字照抄整句，也不只指抄给定首尾。原邀请结尾被移入演讲时，教师明确称为适配演示、并非很合适的演讲结尾，要求改变邀请用词；不能把邀请模板推荐为所有演讲的标准结尾。

**背结构，改小词**：春5主讲义与回放轴的独立口诀。保符合文体的结构，按当前对象、活动、时态和目的改词；与上一口诀职责有关，原名仍各自保留。

**中文→词汇→句型的草稿表**：按春5现场先用中文简记内容，再列将用词汇，最后放入合适句型，不写完整英文草稿。表格空间列序是中文、句型、词汇，步号却为1、3、2；回放轴摘要也写中文→句型→词汇，与现场有差异。这里沿用现场和表头步号，不宣称所有来源一致；“三联草稿表”为整理便称。文体与句型配对只是示例，不是每题固定要求。

### 国庆应用文：修改流程与表达训练

**应用文写作的五步法**：用于修改与批改，原五块为审题与时态核查→结构与要点梳理→衔接与细节优化→语言与句式升级→最终检查清单。现场会按当前问题往返检查；先核身份、目的、要点，再补真实细节与逻辑、改语言、复查常错。它与五审法、六步训练法各自保名，不改成全部应用文唯一写作顺序。

五个编号表达技巧各自使用，不合并为旧三种写作表达方法：

- **换词，简单词变成高级词**：对已准确的内容，按语义、搭配和语体选择更具体或多样的词；不把课堂词对视为恒等替换，不要求常用词全换。
- **加词，丰富语意，增加形副**：给对象或动作补题意允许且相关的修饰，让信息具体；不按形副数量评分，不凭空增加属性。
- **换主语，告别以人开头的大白话**：同一信息可改以事件、物品或概念为主语，并重建谓语和逻辑归属；不禁用人称主语，不把主观意愿改成客观事实。
- **单句变成复合句**：按完整命题之间的真实关系组合句子，保主句与修饰归属；原表也列with／without结构，保原题名，但不把所有这类结构判成含从句的复合句。
- **单一句式变为多句式**：已有内容成立时，按需要用名词化、介词短语、省略或非谓语等减少重复；保原义、逻辑主语和时间关系，不堆句型。

**形容词叠加**：赠46表达训练原名，可用两个语义相容的形容词描写同一对象；按当前对象和搭配选词，不设每句双形容词配额，也不沿用同帧误标的语态判断。

思辨题三个构思模型分别保名：**问题-分析-建议模型**用于解释问题并给针对性建议；**现象-利弊-总结模型**用于评价现象，不强制利弊均等；**观点-论据-论证模型**是国庆视频完整原名，讲义末字写作**观点-论据-论证模**，用相关支持说明观点，不把无据统计当事实。现场讲先陈述问题、现象或观点，主体作相应分析，末尾建议或总结；这是该思辨课的组织口径，不强加到活动执行类，也不从名称补每段句数。以下各按任务调用，不合成所有作文唯一三段模板；原件完整示范、现场框架概述和具体口述操作的证据范围各自保留。

问题-分析-建议模型：先明确本题要处理的问题，再把相关理由、影响或所提措施的作用说具体，让建议接住同一问题，结尾仍回应当前任务。分析可以使用题面已有影响，也可解释措施为什么有用；不能把未给出的成因、既成事实或统计编成题面信息。不是只列泛泛建议，也不要求每条都填满问题、原因、影响、措施等固定槽位。

现象-利弊-总结模型的同题现场另证：先看题目要评价什么、还要求提出什么，再决定利弊详略。题面另要求学习建议时，不能把利处写得过多，挤掉不足与建议；不足不能只列一个标签，要说明它会带来什么具体问题，再让所给建议接住该问题，最后回扣当前主题。详略由本题决定，不把“不足多写”或原例的利弊条数变成统一配额，也不搬网课的具体问题和建议。

观点-论据-论证模型：先明确当前立场，再选能支撑它的理由或具体材料，说明这些材料怎样使该立场成立，最后回扣观点。不要停在理由标签、罗列无关事例或只在末尾拔高；说某事有意义、影响很大，就回查主体中哪一事件、细节或实际影响支撑这句话。理由数量按本题和展开程度决定，不固定三条，也不把范文无出处的统计当真实研究证据。

### 春5文体模板与修辞建议

课名演讲不限制其全部内容为演讲。按当前任务分别选原栏目：**发言稿模板**（引主题、内容、感想祝福）、**建议信模板**（背景与建议、分项建议、希望）、**投稿征文模板**（目的、情况、总结）、**报道模板**（事件、经过、简评）、**人物介绍类模板**（引人物、描述、评价）、**邀请信模板**（邀请、安排与意义、期待回复）、**求助信模板**（表意、原因、希望）、**申请信模板**（意图、优势、期望）、**告知信**（即将发生的事或回复询问）。这些是文体模板目录，不是一套演讲算法；题面要点与交际对象优先。自我介绍在对方需要知道身份时简要交代，不把投稿示例泛化为所有投稿禁止介绍身份。

**先声夺人开头句**、**引人入胜篇中句**、**画龙点睛结尾句**分别是各文体的功能位置栏目，依所选文体完成引入、展开与收束，不把栏目名当跨文体无条件套句法。

演讲中的**排比句式**、**比喻手法**、**反问技巧**、**把握语言节奏**、**丰富词汇表达**分别为修辞和语言建议。并行结构需有真实并列内容，比喻、反问、停顿与长短变化服务当前主题和语气，用词受准确性、搭配和语体约束，不要求五项齐全。

**基础范文／升级范文／优化原因**：春5补充讲义三组范文的比较栏目；各题列四条针对该稿的优化说明，涉及词汇、句式、衔接、精简或立意，三题选取不同，不是每篇都须写满固定四条或完成五项升级。按当前稿的实际问题选用，不把栏目组合命名为另一套“三段式”方法。

**具体升级手法**：not only...but also 倒装；形容词或分词作状语；as 引导倒装；first and foremost 与 last but not least 替换 first 和 last；精简冗余句、严格贴合字数；逻辑词 thus、more importantly。

**制作步骤类写法**：First、Then、Finally 加祈使句动作链。

### 十二字真言

27S暑课堂明确命名“十二字真言”，三组分别为翻译背景、大小三圈、模板呼应：先提取当前相关背景并完成开篇交际目的，正文把内容展开，末尾按文体收束并回扣本题。口头回顾另说“背景翻译”，保其开篇职责称呼，不新立方法。它是本课三部分职责的记忆口诀，不在既有方法之外再造一套整题算法。同课“写作文的三部曲”是这三个功能部分的课堂称呼，原名另保，不与单句升华三部曲混用。能自己准确写出的模板表达不必强背同一句；仍按当前表达缺口练习。

### 大小三圈

同课还分别称“大三圈”和“小三圈”：大三圈负责选相关角度，小三圈负责句内内容、做法、原因或意义的展开，两个子称呼各自保留，都是大小三圈的内部职责，不另立两套整篇算法。小三圈的具体成员与排列按下述来源使用，不统一为每句话都要填满的固定槽。

27S暑讲义有清楚原字，局部回放另证大方向与小句子的分工。需要为开放要点找相关角度、把一条建议或求助内容说具体时，先按“大方向三圈--自我，同学，社会”从自身向同学与周遭、再向社会扩散，选与本题相关的内容，再用“小句子：是什么，为什么，怎么做”细化。现场明确可任挑其中两个组合展开，不要求三项齐全；三条建议的当前示范也允许一条稍详细、其余简化，按内容主次处理，不迁成每题必三条。感谢模板另按“是什么、怎么做、意义是什么”排列，保留其帮助内容、做法、影响的职责，不统一成所有信件的固定小句顺序。大方向帮助想内容，小句子帮助补理由或具体做法；不要求三圈全写、每项拆三句，也不把已给题意改为泛谈社会意义。题面明确内容优先，不额外制造困难或帮助。

题面已经给明具体帮助或做法时，现场明确可以不再从自我、同学、社会重新找角度，直接沿已给帮助说明内容与作用。向身边或更大范围拓展是可选写法，不能为了三圈增加题面不支持的结果。

求助微写作另明确：困难只在自己身上、不能合理扩展到同学时，就留在自身，不硬走大三圈。先把题面背景和困难翻清楚，再按“是什么、怎么做、意义是什么”说明具体困难、希望对方怎么帮、帮助带来的作用；其中任取两个能说清楚也可以。结尾的模板呼应要填回本题具体所求，不能只剩泛泛感谢或求帮忙。这里只迁展开与呼应职责，不固定演讲、简历或发音等例题内容。

同源“政治大题模板”“政治答题模板”是分角度展开的类比黑话，原字各自保留，不另立英语答题算法，也不迁入其他学科要求。“翻译背景”“模板呼应”分别提示交代当前背景、在结尾回扣本题已经写过的具体内容或主题词，让收束接住本题，而不是纯背套话；不凭三个短语拼造新原名“三步法”。本名不与个人--家庭--学校--社会合名，不借阅读大小原则或大词原则。

### 六类书信的本课职责

暑8的建议信、感谢信、求助信，秋3的邀请信、申请信、告知信分别按当前交际任务用模板，不因秋3课名为活动类就全部套邀请结构：

- 建议信：针对实际困难给可执行建议，并说明相关做法或理由；不为模板凑三条、三种句型。
- 感谢信：交代对方做了什么、怎样帮助自己及其作用，再回应谢意；暑8现场明确感谢信不需要再拔高成读后续写式升华。微写作两处误沿用“第二段：建议”标签，原音实际按帮助与影响展开，不能据标签把感谢主体写成给对方建议。
- 求助信：说清哪里有困难、希望对方具体帮什么，困难与所求要相接，不只写泛泛求帮忙。
- 邀请信：交代当前活动、对方受邀角色及必要安排，完成邀请与合适的收束；参赛者、评委、嘉宾等身份不能互换。秋3两题均先发出邀请，再说明时间地点与具体活动，末尾回应期待或题目所需陪同；准确简单开头可以保留，时段表达不必强用同一分词结构。明确邀请对方到场而题面未给时间时，可补合理且不冲突的安排，服务对方参加，不强加题目不需要的完整时间表或联系方式。
- 申请信：先说明申请与适合该职位，再将题面支持的能力／品质连到能做什么、相关经历连到所带来的能力，最后按任务表达意愿或承诺。秋3模板现场允许两项已经充实时不加第三项知识优势，措辞也可选择；不为套模板虚构履历，不以品质词堆砌代替岗位关联，不设恰三优势或指定从句配额。
- 告知信：原件分告知即将发生的事、回复关于某事的询问两类；把当前安排、变更或对方所问逐项说清，再给必要提醒。秋3讲座题先说明目的与主题，再交代安排和主讲人、内容作用与提醒；面对同学收束时不用过分夸张的敬语。调整安排题则处理具体变化，再补恢复时间、提醒和歉意，不硬套“举办活动的意义”；提醒表达可以换，不必固定用某句型，不能因背过迟到者句式就为新题编制入场禁令。署名依题目身份，不能把学生会或部门名推广为所有告知信的固定署名，也不添无关邀请或回复请求。

“黄金模版”下的“基本模版”“升级模版”是各文体表达素材。秋3局部回放明确模板提供写作思路，不要求逐字背同一句；结构先服从本题，升级不等于评分更高，准确的简单句可以保留。六类模板各自的题材、人名、时间地点、人物品质和活动评价不带入新题。表内可选结尾按目的择用，不为了背过而全部堆入；等号或对应词也须核真实语义，不能把发生时的表达无条件替换为假设条件。

### 综合运用小结

27S秋回放轴的原栏目名为“综合运用小结”，没有“五审法”原名。其五项是：核文体与写作目的，并在其中核身份、收信对象；核全部内容要点；核关键细节信息；核格式；核词数。可据本题逐项检查任务完成度，不替代本模块五审法的文体、对象、要点、逻辑、语言，也不因五项就另命名一套五审法。题干有交际指令词时先据它确认目的，没有时依据完整任务判断；细节、格式及词数以当前题目为准。

回放轴的约80词、上下20词是该课训练口径，不新增官方评分阈值或逐项扣分；评分仍按本模块原有规范。“尽量用提示词”服务当前练习，不机械塞词；避免第一人称作主语、背模板、衡水体等建议不变成逐句禁令或美观加分项。

### 训练栏目与阶段

“基础夯实——句子构建训练”“能力进阶——话题金句汉译英”“综合运用——微写作实战”分别是句子、翻译和篇章练习栏目，不能逐个升为整题算法。暑8汉译英列谓语动词、句子主要结构、主谓宾、添加修饰、替换部分高阶词语，并先查意思完整、无语法错误；现场也按此讲明组句依赖，称为简化句子的反向过程，不另造“句子五步法”原名。本课明确前四项准确做好即可，高阶替换可后练；基础已经能准确表达时也可直接写，不强制每句慢拆或做满五层升级，不与本模块旧句子写作思路改为同一原名。

两个不同句子练习都回到“意思涵盖完全、无语法错误”收束，再看修饰与表达优化。同句重复复杂从句时，可把其中一处改成合义的名词短语，使表达紧凑；这是当前句子的可选优化，不是相同句型再现就有语法错。课内单句评分、练习数量与词语偏好不改本模块整篇评分，也不将准确常用表达列为禁用词。

秋3“人的品质”“核心短语积累”“核心短语”是词汇素材栏目，“亮点说明”是当前参考稿表达的说明。品质、词性、搭配及修饰都按当前任务核对，不把同栏词视为同义词，不由示例的从句数量造结构配额。

暑8“写对写完整→写好→写出彩”是暑假、秋季寒假、春季的训练分流，按学生实际缺口选择，季节变化不自动要求升级词汇或另辟蹊径。“衡水体：矮胖圆”是该课书写训练说法，评分仍只按既有书写评价边界，不另设字体标准分。

## 补充课程名称与材料身份

以下逐名说明已有职责；整理简称、材料栏目和例题示范不升级为课程独立算法。

- 劫匪插葱 反向进行：原口诀表述，已有模块拆组／拼贴职责见反向劫匪插葱小节；不凭字面拆造顺序。
- 读-背-仿（三步走）：原训练表述，对应本模块熟读英文、记中文大意、富兰克林仿写的职责，不是临场必走三遍。
- 核心要素：人物介绍原栏目，含身份、成就、品质、社会影响；国籍如适用才写，内容依题选择，不强制四段。
- 品质+事例：人物主体段的一种可选构思逻辑，与时间轴择适合者使用，不强制两套都做或固定三品质。
- 句式多样化：人物课的句式素材栏目，按内容选择定语从句、分词结构、强调句，不要求三种齐全。
- 好作文三步：课程检查／训练标题，内容是审题格式与考点、内容语言丰富度与细节、卷面训练；不压成唯一严格程序或美观评分项。
- 蓝色标注：暑13该讲扩充语料的材料约定，熟读积累但不要求背诵；绿色是该讲重点词汇短语的背用要求。颜色含义不跨材料泛化，陌生题按语境选用，不据颜色扣分。
- 应用文写作前三步骤：历史人物投稿例的审题示范，具体动作见投稿小节；不能泛化为全部投稿禁止自我介绍或一律过去时。
- 报道“一般结构”：原文体框架，时间地点目的参与者→经过→评价或感悟，按当前报道任务用，不套邀请结构。
- 活动三段式：整理简称，对应活动课原名三段式，不冒充另一套课程原名。
- 三种句子生成法：整理者总称，对应的课程总称是三种写作表达方法，不另增第四种方法。
- 人物四件套：整理者对核心要素的便称，未核为课程逐字原名。
- 句式多样化三件套：整理者称呼，相关三类素材已核，组合名称未核为原名。
- 要点—句型—词汇三联草稿表：整理名称，实际原表操作仍是中文→词汇→句型，不按便称或表列空间顺序倒置。
- 初阶：填空训练（强化重点句型）：赠课原训练栏目，读熟后遮词、回忆、核错，基础不足先熟读；不是新题现场作答算法。
- 刻意仿写：赠课训练栏目，保实际语义关系与可迁结构、按新对象和任务改写，不复刻原例人物事实。
- 扩展能力：国庆的课程组织栏目，涉及五大话题与九大句型／九大句式；不是新解题法。国庆第2讲“校园生活与个人成长”的高级句子素材中，九类为强调句、倒装句、虚拟语气、非谓语动词结构、让步状语从句、双重否定、定语从句、主语从句、谚语／名人名言引用。按当前要表达的关系和自己能准确使用的结构选练，课堂允许先选熟悉的三类，不是单篇要用满九类，也不是九套构思算法。寒4另解释八／九大句型的计数差别在虚拟语气：不采用时称八大，表达能力与语境允许采用时称九大；不据此断言寒4与全部国庆讲次都使用上述同一目录。五大话题按各来源的实际栏目保留，不用零散主题凑目录；数量均不作单篇配额。
- 五大话题：国庆后续素材分别为校园生活与个人成长、科技发展与社会影响、环境保护与可持续发展、文化交流与传统文化、社会现象与热点问题；第2讲从校园开始，第4讲科技后接环境，第5讲明确第四文化、第五社会。用于按当前主题调用相关词汇、句式和范文，不能见到一个主题就把其全部子话题塞入作文。国庆第1讲另在“五大话题”栏写“人物介绍”，保留该来源的实际表述，不把它静默替换成后续清单的成员，也不将六名凑成同一五项目录。
- 升级复杂句：国庆单句表达训练称呼，按实际原因、建议、目的或结果组织复杂表达，不把所有合句都强冠两简一复从。
- 功能句式、升华句、部分金句：课程对不同素材的背用要求；国庆偏重点背功能与错漏，赠49另要求整篇背熟，分来源保留训练差异，不变为每篇必须逐项使用。

## 批改交付格式

不要展示题型判断过程。按以下顺序输出：

书写属于条件项：只有看到原始手写稿且书写已经影响交际时，才在整体结论或重点修改中简要说明降档依据；其余情况不单列“书写美观性”。

1. 整体结论：给出分数区间或建议分数、所属档次及最关键证据；先肯定一项真实优点，再指出一个最优先改进点。
2. 五审结果：分别写文体、对象、要点、逻辑、语言。要点用“已覆盖 / 不充分 / 遗漏 / 偏离”标记。
3. 细致修改：逐处给出原句、建议改法和原因，覆盖明确的语法及相关语言错误；同类错误可合并解释，但保留各处位置与改法。另行说明可选表达优化，不把风格偏好当成语法错误。
4. 结构优化：用简短提纲说明开头、主体、结尾怎样重排或补全。
5. 修改稿：保留学生原意和能用的句子，先补任务与逻辑，再改语言；不得擅自加入改变任务的信息。
6. 方法练习：从单句锚定、模块组篇、长句重构或富兰克林法中选一个最适合本次问题的练习。
7. 配套素材：仅在有帮助时给 3–5 个可迁移表达或一个简短骨架，不用大段模板淹没反馈。

语气口语化、具体、鼓励式，但不能虚构优点或淡化会影响分数的关键问题。
