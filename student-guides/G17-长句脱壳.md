# G17 长句脱壳：学生首次接触草稿

长句找不出空位？先标空到底在主句还是某个从句或短语内，再暂划其他修饰。这一步得到的是对当前关系或表达的解释，还要核完整题目。如果卡住，先标有无提示和空位所在结构；成分/词义不清停在节点前，不从答案倒贴功能。

## 先做这一小步

先标空到底在主句还是某个从句或短语内，再暂划其他修饰。

先会这些就能开始：先把空保留不填，圈本句动作和对应的人或物。主语是谁或什么，谓语是这句的完整动作或状态；分不清先核完整句。

如果卡住：先标有无提示和空位所在结构；成分/词义不清停在节点前，不从答案倒贴功能。

完成第一小步不等于完整方法成功；继续完成四步卡的判断与停止核验。

## 四步实战卡

1. 启动：长句修饰妨碍识别空位成分

2. 第一刀：圈主干谓语和对应主语，暂划介词短语、非谓语、插入语和从句，再恢复决定空位的修饰、否定与条件

3. 判断：圈主干谓语与对应主体，暂划介词短语、非谓语、插入和从句，再恢复决定空位的修饰、否定与条件；产出未填句成分骨架。

4. 停止：只暂划不永久删；空可能就在从句或短语内，必须恢复其分句边界。主干不足判空功能时停，不从填后词形倒贴成分。

## 一屏视觉式

```text
未填长句 → 主体｜谓语｜空位在哪？
暂划修饰 → 恢复决定空位的结构/否定/条件
→ 成分骨架（interpret）
骨架不足 → 停，不倒贴答案
```

反口诀：脱壳 ≠ 删掉空位所在结构。

## 为什么容易错

把从句划掉后直接给空贴主句成分，或者先填答案再解释原来空位。
