# G01 先判空位：学生首次接触版

看到括号里的词就立即变形时，先停。第一眼只问：这个空有没有提示词？没有，就看这个位置需要限定、介词、指代、连接还是句间逻辑。有，就先在未填句中判定该位置要名、形、副、代、数还是动。只有已确认这里需要动词形式，才再分谓语和非谓语。到达具体知识节点就停止总树，改用该节点的句法、搭配和句意判据。换任何新题，有无提示+空位功能都能重复。

你可以直接说：这个空先判位置，别急着变词。

## 四步实战卡

1. 启动：任何语法填空还未确定空位功能时。
2. 第一刀：标有/无提示词，在未填句中圈出决定空位的主干与标点。
3. 判断：无提示走功能词节点，有提示走词性节点，确认需要动词才分谓语/非谓语。
4. 停止：到达明确节点就停总树，不用方法名代替节点语法判据。

## 10 秒版

看到空先别变词。先问有没有提示词，再问这个位置要什么。确认要动词了，才分谓语和非谓语。

## 30 秒版

有提示词时，先判空位要名、形、副、代、数还是动；无提示词时，先查限定、介词、指代、连接或句间逻辑。比如 `environmental ___ (protect)` 里括号是动词，但空位要名词中心，所以走名词节点。刹车句：提示词词性不等于答案词性。

## 90 秒版

这是一棵路由树，不是语法知识清单。先以未填句为准划清分句、主干、空位和标点。没有提示词，去功能词路线；有提示词，先判空位需要的词性或成分，然后才处理派生或形态。反例一：`environmental ___ (protect)` 的动词提示不会把空位变成动词位置，这里要的是名词 `protection`。反例二：介词后需要名词性成分，但课程例 `After spending...` 说明 doing 也能在这里工作，所以不能见介词就一律变派生名词。决策树只负责送你到正确节点，最后还要填回句子核对句法、搭配和句意。

挑战：先不填词，只说这个空有没有提示词、需要什么功能或词性，以及下一步该进哪个节点。

## 一屏视觉式

```text
空位
  ↓ 有提示词？
无 → 限定 / 介词 / 指代 / 连接 / 句间逻辑
有 → 位置要什么？
       名 / 形 / 副 / 代 / 数 / 动
                               ↓
                        谓语 / 非谓语
```

反口诀：提示词词性 ≠ 答案词性。
