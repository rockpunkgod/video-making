# G01 先判空位：学生首次接触草稿

任何语法空开始时先在未填句取证。先标有无提示词，再圈分句主干、标点及空前后的支配或修饰关系：无提示词去功能词节点，有提示词先判名、形、副、代、数或动；确认需动词才分谓语/非谓语。产物只是知识节点，不是答案。反例：提示protect但位置要名词；介词后需要名词性成分也不必一律派生名词，doing可有相应功能。句法功能不明先补完整句，到节点就改用具体规则，再回填核搭配与句意。换题仍判新位置，不背提示词变形套路。挑战：不填词，只标有无提示词、空位功能、决定它的词与下一节点。

## 四步实战卡

1. 启动：看到一个语法填空，还没确定这个位置需要什么功能或词性。

2. 第一刀：先标有/无提示词，再在未填句中圈出决定空位功能的主干、标点、限定或连接关系。

3. 判断：无提示词进功能词节点；有提示词进空位词性节点；确认需要动词才进谓语/非谓语。

4. 停止：空位功能或必要句子未确认时先停；到达知识节点即停止总路线，改用节点句法、搭配与句意核验，不把路由当答案。

Stop Rule：空位功能或必要句子未确认时先停；到达知识节点即停止总路线，改用节点句法、搭配与句意核验，不把路由当答案。

## 10 秒版

看到空先别变词。先标有无提示词，再问位置要什么；确认要动词，才分谓语与非谓语。

## 30 秒版

括号里的词先别变。标有无提示词，再圈未填句里决定空位功能的限定、修饰、连接或主干。比如environmental ___ (protect)需要名词中心，不因提示词是动词就走动词路。无提示词进功能词；到节点后停总路线，用该节点句法、搭配与句意求证。

## 一屏视觉式

```text
空位
  ↓ 有提示词？
┌─ 无 → 限定 / 介词 / 指代 / 连接 / 句间逻辑
└─ 有 → 这个位置需要什么？
           名 / 形 / 副 / 代 / 数 / 动
                                     ↓
                              确认要动词
                                     ↓
                                谓语 / 非谓语
```

反口诀：提示词词性 ≠ 答案词性。

## 为什么容易错

看到括号里的词就立即变形，尤其看到动词就直接进谓语/非谓语。

## 反例与挑战

反例/边界示意（不等于已核验真题）：`environmental ___ (protect)` 的提示词是动词，但空位需要被形容词修饰的名词中心，应走名词节点而非非谓语节点。；介词后虽是名词性位置，但课程例 `After spending...` 说明 doing 可作名词性成分，不能见介词就一律派生名词。

先不填词，只判断这个空有无提示词、在句中需要什么成分或词性，并说出下一个决策树节点。
