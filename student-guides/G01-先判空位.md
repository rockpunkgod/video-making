## 四步实战卡

1. 启动：看到一个语法填空，还没确定这个位置需要什么功能或词性。

2. 第一刀：先标有/无提示词，再在未填句中圈出决定空位功能的主干、标点、限定或连接关系。

3. 判断：无提示词进功能词节点；有提示词进空位词性节点；确认需要动词才进谓语/非谓语。

4. 停止：空位功能或必要句子未确认时先停；到达知识节点即停止总路线，改用节点句法、搭配与句意核验，不把路由当答案。

## 一屏视觉式

```text
空位
  ↓ 有提示词？
┌─ 无 → 限定 / 介词 / 指代 / 连接 / 句间逻辑
└─ 有 → 这个位置需要什么？
           名 / 形 / 副 / 代 / 数 / 动
                                     ↓
                              确认要动词
                                     ↓
                                谓语 / 非谓语
```

反口诀：提示词词性 ≠ 答案词性。

## 为什么容易错

看到括号里的词就立即变形，尤其看到动词就直接进谓语/非谓语。

## 反例与挑战

反例/边界示意（不等于已核验真题）：`environmental ___ (protect)` 的提示词是动词，但空位需要被形容词修饰的名词中心，应走名词节点而非非谓语节点。；介词后虽是名词性位置，但课程例 `After spending...` 说明 doing 可作名词性成分，不能见介词就一律派生名词。
