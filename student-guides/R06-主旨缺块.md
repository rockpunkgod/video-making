# R06 主旨缺块：学生首次接触版

全文主旨、写作目的或标题题中，两个选项都相关时，别先选范围大的。第一眼去开头、结尾和各段主要任务中，写出全文 2–4 个不可缺核心块 A+B+C。再看每个选项缺了哪块、多了哪块，或把块间的对比、因果、变化关系换错。明确细节题、单段题或主要段落不全时停。换文体后，覆盖+关系的检查仍能重复。

你可以直接说：这个主旨缺块，先把全文拼齐再选。

## 四步实战卡

1. 启动：全文主旨、目的或标题题中，多个选项都相关却一直二选一。

2. 第一刀：先写出全文 2–4 个不可缺核心块 A+B+C。

3. 判断：对照候选是否缺块、多块或把块间关系换错。

4. 停止：明确细节题、单段题或主要段落不全时停止。

Stop Rule：范围大，不等于主旨对。

## 10 秒版

主旨题二选一时，先把全文拼成 A+B+C。选项缺一块或换错块间关系，就不完整。

## 30 秒版

主旨、目的或标题题里，两项都相关时，先从全文写出 A+B+C。比如候选1只有 A+B，就缺 C；候选2虽有 A+B+C，还要检查它有没有换错关系。刹车句：范围大不等于主旨对。

## 90 秒版

只有全文主旨、写作目的或最佳标题才启动这个方法。从开头、结尾和各段主要任务提取 2–4 个贯穿全文的核心块，然后把候选拆成谈什么与对它作什么判断。反例是：一个选项包含的词更多，却把原文对比改成因果，它仍然错；另一个选项字少，却用上位概念准确覆盖 A+B+C，不能因它短就排。指出以偏概全时，你必须能说出它缺的具体核心块。

挑战：先不选主旨，用三个短语写出全文不能少的块，再给每个选项标缺块、多块或错关系。

## 一屏视觉式

```text
全文：A + B + C
候选1：A + B       → 缺 C
候选2：A + B + C   → 再查关系
候选3：A + C       → 关系被换
```

反口诀：范围最大 ≠ 主旨。

## 为什么容易错

把抽象、范围大、包含其他选项或出现段数多当作正确主旨。

## 反例与挑战

反例/边界示意（不等于已核验真题）：候选覆盖的词更多，但把原文的对比改成因果，仍应排除。；候选字面较短，但用上位概念准确覆盖 A+B+C 且关系正确，不能因词少排除。

先不选主旨，用三个短语写出全文不能少的核心块，再标注每个选项缺了哪块或换了什么关系。
